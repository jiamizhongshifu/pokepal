## 来源与资源修正

模型来自 [PokeMiners Pokémon GO 资源存档](https://github.com/PokeMiners/pogo_assets/tree/c7ea15aa8bee189efba23fa5306a3e7aa71c09b5/3D%20Assets/Pokemon)，固定 revision `c7ea15aa8bee189efba23fa5306a3e7aa71c09b5`（2020-11-27）。本轮新增下载 603 个原始文件、501,710,125 字节，每个文件校验固定 Git blob SHA-1 并记录 SHA-256。

**模型不是从本次下载的 APK 中提取的。** 初代 151 只叫声来自此前下载并审计的 Pokémon GO 0.29.0 APK；6 只第二世代继续使用已有音频。新增图鉴数据及图片来自 [PokéAPI](https://pokeapi.co/docs/v2) 与其 sprites 仓库，具体来源和哈希保存在证据目录。

原始输入没有改写，转换处理包括：

- 按普通形态逐只检查身体和眼部贴图。`#数字` 文件名不能代表普通／异色，已显式修正 22 只眼部或面部配色。
- 按 UV tile 恢复身体和表情材质；蛋蛋、椰蛋树等保留各自面部区域。
- 派拉斯、摩鲁蛾恢复透明角膜和高光层；臭泥、臭臭泥移除依赖 Unity 滚动着色器的重叠黏液层，保留完整身体网格。
- 穿山鼠、穿山王移除攻击用球形替身；去除重复性别与调试网格。
- 大岩蛇源 FBX 的 Blender rest bones 与 cluster bind 存在统一平移偏差。依据原文件矩阵恢复网格偏移 `(0, 0.7736458778, -2.8799643517)`，修复身体各节分离；原始骨骼动作不变。
- 隆隆石、急冻鸟减面到 7,900 面；臭泥、臭臭泥移除重复层后无需减面。
- 默认姿态匹配待机首帧；移动通过独立根节点对齐首帧地面原点，保留原始扑翼、起伏和关节动作。
