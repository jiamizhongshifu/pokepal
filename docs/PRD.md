| 项 | 内容 |
|---|---|
| 版本 | v0.2（MVP 已实现，家园 3D 化） |
| 日期 | 2026-10-14 |
| 作者 | 钟青彪（产品负责人 / 家长） |

---

## 1. 背景与目标

### 1.1 背景

家里 4 岁的宝宝喜欢宝可梦。希望做一个类似 Pokémon HOME 的互动空间，让他和喜欢的宝可梦相处，并在过程中自然地听、说、认、写英文，达到"磨耳朵"的效果。

对标参考：
- **Pokémon HOME**：集中收纳、图鉴、神秘礼物、宝可梦资料页。本项目借鉴"收纳 + 图鉴 + 资料"的骨架，去掉交换、对战等联网玩法。
- **Pokémon Playhouse**（官方 3–5 岁应用）：无需识字、全程旁白、蛋孵化作为长期奖励、无内购无数据收集。
- **Pokémon Smile**（官方刷牙应用）：把日常任务转化为"救出/捕捉宝可梦"的即时奖励，1–3 分钟定时，照片贴纸作为二次奖励。
- **littleprince.dev**：AI 辅助 16 天完成的 3D 叙事游戏，技术栈见 `research-littleprince-techstack.md`；本项目借鉴其资源懒加载、本地存档和配置化多语言做法，不采用 Unity + WebGPU。

### 1.2 产品目标

| 目标 | 说明 |
|---|---|
| G1 英语输入 | 每次游玩 10–15 分钟内，宝宝听到 ≥ 60 句自然英语，核心词汇 ≥ 15 个 |
| G2 英语输出 | 每次游玩至少完成 5 次开口跟读，宝宝愿意主动说 |
| G3 认读与书写 | 认识 26 个大写字母与主题词图；通过手指描红完成"写"的前书写训练 |
| G4 情感动机 | 通过收集、养成、奖励让宝宝每天主动要求玩，而不是被安排 |
| G5 家长可控 | 家长能设定每日时长、看到学习报告、随时调整难度 |

### 1.3 非目标（明确不做）

- 不做对战、PvP、联网交换、社交。
- 不做内购、广告、任何现金交易。
- 不做对外发布或分发，宝可梦素材仅家庭内使用。
- 不做复杂剧情或文字阅读要求，4 岁儿童不需要识字也能玩。
- 第一版不做 3D 全场景，用 2.5D 场景 + 官方风格立绘。

## 2. 用户画像与使用场景

### 2.1 主要用户：宝宝（4 岁）

- 不识字，能听懂简单中文指令，英语零基础或少量单词。
- 注意力单次 5–10 分钟，喜欢即时反馈、声音和动效。
- 精细动作：能点、拖、用手指画线，不能精准双击或长按。
- 情绪：失败会沮丧，要避免"抓不到"的挫败；喜欢重复看喜欢的角色。

### 2.2 次要用户：家长

- 每天陪玩或旁观，负责开启、结束、调整难度。
- 想知道今天学了什么、说了什么，希望有录音回放。
- 关心隐私、时长、无广告。

### 2.3 典型一天

1. 晚饭后家长打开 iPad，宝宝点自己的头像进入。
2. 家园里皮卡丘在睡觉，宝宝点它，它醒来说 "Good evening!"；宝宝跟读。
3. 任务板出现今天的三个小任务（听一听、说一说、画一画），完成后能量条满。
4. 能量兑换一个"超级球"，宝宝在草丛里选喜欢的妙蛙种子，扔球，抓到。
5. 妙蛙种子进入图鉴和家园，宝宝给它喂树果，听它叫，然后"晚安"结束。
6. 家长在报告页看到今天的跟读录音和新词。

## 3. 核心玩法与系统

整体循环：

```
英语小任务 → 获得能量 → 兑换精灵球（分等级） → 捕捉宝可梦（按稀有度）
      ↑                                                      ↓
  家长报告 ←  家园互动 / 养成（亲密度、进化） ←  进入图鉴 + 家园
```

### 3.1 英语学习任务系统（能量来源）

任务按四项技能分类，每天从词库推 3–5 个任务，每个 1–3 分钟，全程中英双语旁白。

| 技能 | 任务类型 | 玩法示例 | 产出 |
|---|---|---|---|
| 听（磨耳朵） | 听指令做动作 | "Touch the red Pokémon." 点中即可 | 能量 +1 |
| 听 | 听叫声猜宝可梦 | 播放叫声 + 三张立绘选一 | 能量 +1 |
| 说 | 跟读单词/短句 | 宝可梦示范 "Water!"，宝宝按住麦克风说 | 能量 +2 |
| 说 | 打招呼与回应 | 宝可梦说 "Hello!"，等待宝宝回应任意语音 | 能量 +1 |
| 读 | 字母配对 | 把字母 P 拖到 Pikachu | 能量 +1 |
| 读 | 词图配对 | 听 "apple"，从三张图中选 | 能量 +1 |
| 写 | 手指描红 | 沿虚线写大写字母、数字或简单形状 | 能量 +2 |
| 综合 | 迷你故事 | 20 秒动画对话，中间停一次让宝宝选择 | 能量 +2 |

规则：
- **不允许失败**：答错时宝可梦温柔提示并缩小选项，最多两次后直接演示正确答案，仍给能量。
- **跟读判定宽松**：云端发音评分只做三档（再试试 / 不错 / 很棒），任何有效语音都给能量，评分只影响星星数。
- **难度自适应**：按宝宝近 7 天正确率和跟读得分调整词库层级（L1 单词 → L2 两词短语 → L3 短句）。
- **可重复**：宝宝可以重玩喜欢的任务，但当日能量只按前 5 次计。

### 3.2 词库设计（英语内容）

主题词库围绕宝可梦自然展开，每个主题 8–12 个词，每词带中英文、图片、真人或 TTS 音频、例句。

| 主题 | 词例 | 关联宝可梦 |
|---|---|---|
| 颜色 | red, yellow, blue, green, pink | 按 PokéAPI `color` 字段 |
| 数字 1–10 | one … ten | 数宝可梦、数树果 |
| 属性 | fire, water, grass, electric | 按 `types` |
| 身体 | ears, tail, eyes, nose | 指认立绘部位 |
| 动作 | jump, run, sleep, eat, swim | 家园互动动画 |
| 情绪 | happy, sad, sleepy, hungry | 宝可梦状态 |
| 食物 | berry, apple, cake, water | 喂食 |
| 日常 | hello, bye, thank you, good night | 进出家园 |
| 大小/天气 | big, small, sunny, rainy | 家园天气 |

字母阶段：A–Z 大写，每个字母绑定一个宝可梦（A Abra、B Bulbasaur、P Pikachu …），用作"读"和"写"任务。

### 3.3 能量与精灵球（经济系统）

| 精灵球 | 所需能量 | 可捕捉稀有度 | 预期获得频率 |
|---|---|---|---|
| 精灵球 Poké Ball | 5 | 普通 | 每天 1 个 |
| 超级球 Great Ball | 10 | 普通 + 少见 | 两天 1 个 |
| 高级球 Ultra Ball | 20 | 普通 + 少见 + 稀有 | 每周 1 个 |
| 大师球 Master Ball | 连续 7 天完成任务 | 任意，含传说 | 每周最多 1 个 |

稀有度由 PokéAPI 字段自动划分：
- 普通：`capture_rate ≥ 150` 或 `is_baby`
- 少见：`capture_rate 60–149`
- 稀有：`capture_rate < 60`，或进化链最终形态
- 传说：`is_legendary` / `is_mythical`

每日能量上限 15，防止过度游玩；未用完的能量次日保留。

### 3.4 捕捉玩法

1. 宝宝持球进入"草丛"（按栖息地分区：森林、水边、草地、山洞、城市）。
2. 当日出现 6 只宝可梦，按球等级决定出现池；宝宝喜欢的宝可梦可由家长在后台"置顶"，保证出现。
3. 宝宝点选目标，宝可梦说 "Hi! I'm Bulbasaur."；宝宝跟读名字（可跳过）。
4. 拖动精灵球扔出，球摇三下，**必定成功**；仅传说级加一次"再扔一次"的悬念。
5. 捕捉成功动画 + 中英双语播报 "You caught Bulbasaur! 你抓到了妙蛙种子！"，进入图鉴。

### 3.5 训练师图鉴

每只已捕捉宝可梦的资料页，所有文字都可点读：

- 大图（官方立绘）+ 中英文名 + 叫声按钮（PokéAPI cries）
- 分类（如"种子宝可梦 / Seed Pokémon"）、属性图标、身高体重（用"比宝宝高/矮"的方式呈现）
- 幼儿版图鉴描述：由 LLM 把官方描述改写成 1–2 句中英对照的简单话，预生成并由家长审核
- "我和它学的词"：关联已学词汇与跟读录音
- 亲密度等级、进化进度、捕捉日期
- 未捕捉的以剪影显示，点击播放叫声作为线索

图鉴范围第一版限定初代 151 只，后续按宝宝兴趣扩展。

### 3.6 家园（养成空间）

类似 Pokémon HOME 的收纳空间，但以"生活"为主：

- **分区**：按栖息地分为 5 个区域，每区容纳 10 只，宝可梦自动分配，宝宝可拖动调换。
- **生活轨迹**：每只宝可梦有一天的作息表（早上吃饭、中午玩耍、下午洗澡、晚上睡觉），随真实时间变化；进入家园时看到的状态不同。
- **爱好**：根据属性与颜色生成 2 个爱好（火系爱晒太阳、水系爱游泳、皮卡丘爱吃番茄酱），体现在偏好的互动和道具。
- **互动**：摸头、喂树果、洗澡、扔球、拍照、唱歌、晚安。每个互动触发一句英语 + 一个跟读机会，例如喂食时 "Yummy! Thank you!"。
- **亲密度**：互动与完成任务提升亲密度，5 级满级；达到阈值解锁进化仪式（进化为养成里程碑，不强制）。
- **装饰**：任务奖励的贴纸、帽子、家具可摆放在家园，宝宝自己布置。
- **相册**：拍照留念，可加贴纸，家长可导出。

### 3.7 奖励与激励

| 奖励 | 触发 | 作用 |
|---|---|---|
| 能量 | 完成任务 | 兑换精灵球 |
| 星星 | 跟读评分 | 累计换贴纸 |
| 贴纸 / 帽子 | 每日全部任务完成 | 装饰家园与相册 |
| 训练师徽章 | 阶段目标（抓满 10 只、学会 26 个字母） | 展示在训练师卡 |
| 神秘礼物 | 家长手动发放 | 家长奖励现实好行为 |
| 蛋孵化 | 连续游玩天数 | 长期目标，孵出惊喜宝可梦 |

原则：奖励只做正向，不扣除、不惩罚、不倒计时施压。

### 3.8 家长模式

- **家长门**：长按 3 秒 + 回答简单算术进入。
- **设置**：每日时长（默认 15 分钟）、任务数量、词库难度、置顶宝可梦、是否启用云端语音评分、TTS 声音选择。
- **报告**：每日听到的词与句、跟读录音回放、正确率趋势、收集进度。
- **数据**：一键导出/备份存档，一键清空。

## 4. 用户体验要求（4 岁适配）

- 全程中英双语语音，无必须阅读的文字；中文旁白为主，英文由宝可梦说。
- 可点击区域 ≥ 64 px，无双击、无长按（家长门除外）、无复杂手势。
- 每个界面只有一个主操作，返回键固定在左上角。
- 单次会话到时长后由宝可梦"困了"自然收尾，不弹窗、不强制退出。
- 声音：每个操作有反馈音；跟读时显示声波动画，让宝宝知道"在听"。
- 界面色彩明亮、动画平滑，避免闪烁。
- 横屏为主（iPad），兼容 Mac 浏览器。

## 5. 技术方案建议

| 层 | 选型 | 理由 |
|---|---|---|
| 客户端 | Web 应用（PWA），React + TypeScript + Vite | 跨 iPad/Mac，可加到主屏全屏运行，AI 辅助开发效率高 |
| 渲染 | Three.js + React Three Fiber（3D 家园） | WebGL2 兼容 iPad Safari，无需 WebGPU；环境用 Kenney Nature Kit（CC0）glTF 模型，同模型合并为实例化网格 |
| 宝可梦 3D | 默认立绘立牌；可选 Tripo 图生 3D + 绑骨 + 待机/走路动画 | 有 GLB 时自动替换立牌 |
| 视觉系统 | 参考《宝可梦 风/波》：热带海岛场景、薄荷到海蓝渐变、白边卡片、渐变飘带标题、卷浪纹带、海军蓝导航；昼夜双主题；图标全部自绘 SVG | 只借鉴设计语言，不使用官网素材 |
| 宝可梦数据 | PokéAPI（REST/GraphQL），构建时拉取并本地缓存 | 提供中英文名、分类、描述、叫声（.ogg）、HOME 立绘、官方插画、`capture_rate`、`color`、`habitat`、进化链；需按其公平使用政策本地缓存 |
| 语音合成 | 首选浏览器 Web Speech API；云端可选 Azure Neural TTS（儿童向声音）或豆包 TTS | 离线可用，云端音质更好；所有固定文案预生成音频离线包 |
| 语音识别/评分 | Azure Pronunciation Assessment（带参考文本、放宽儿童阈值）；离线退化为 Web Speech 识别或"任意语音即通过" | Azure 文档明确支持为儿童放宽阈值；评分不作硬判定 |
| 幼儿版描述 | Claude API 批量改写 + 家长审核后固化为 JSON | 一次生成，不在运行时调用 |
| 存储 | IndexedDB（Dexie）本地存档 + 可选 iCloud/网盘导出 | 无需账号，隐私最优 |
| 托管 | 本地运行或家庭 NAS/Cloudflare Pages 私有访问 | 不公开 |

资产与合规：
- 宝可梦图像与叫声来自 PokéAPI 社区镜像，属 The Pokémon Company 版权，仅限家庭内部使用，不得公开部署或商用。
- 语音录音只保存在本地，云端评分请求不保留音频（Azure 默认不存储）；可在家长模式彻底关闭云端功能。

## 9. 风险与应对

| 风险 | 应对 |
|---|---|
| 儿童语音识别准确率低，评分打击积极性 | 评分只做鼓励性三档，任何语音都给能量；家长可关闭评分 |
| 过度游玩或只玩家园不做任务 | 每日能量上限、时长自然收尾；家园互动也内嵌跟读 |
| PokéAPI 不可用或限流 | 构建期一次性拉取，运行期全离线 |
| 版权风险 | 仅家庭使用、不公开部署、不分发安装包 |
| iPad Safari 兼容（麦克风权限、自动播放） | 首次进入由家长点一次授权；音频在用户手势后解锁 |
| 宝宝兴趣转移 | 家长置顶宝可梦、神秘礼物、按兴趣扩展词库主题 |

## 10. 待决策事项

1. 主要设备是 iPad 还是 Mac？影响横竖屏与麦克风方案。
2. 是否接受云端语音评分（Azure 或豆包）产生的少量费用，还是先纯离线？
3. 宝宝目前最喜欢的 5–10 只宝可梦，用于 MVP 优先制作与置顶。
4. 英文语音希望用 TTS 还是家长自己录制（家长声音对幼儿更亲切，但工作量大）。
5. 是否需要中文识字同步训练（本 PRD 默认只做英文）。
