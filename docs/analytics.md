## 采集边界

仅 `online` 构建、`pokepal-online.pages.dev` 正式域名、家长单独开启时加载 Google 脚本。默认关闭；开发、预览域名、开源 fork 和移动端不统计。衡量 ID 是公开标识，不是密钥；fork 需自行建立资源和修改域名，不能复用本项目统计。

家长可以从首次须知、家长中心 → 应用维护、或 `/privacy/` 开关访问统计。阅读须知不等于同意统计。选择保存 180 天；暂停试用和清空数据会关闭统计。Cookie 使用 `pokepal` 前缀且为会话级；关闭时清除本页可访问的统计 Cookie。

只发送白名单页面名称与不带参数的虚拟页面地址，例如 `/lesson/`、`/story/`；来源只保留网站 origin。不会发送姓名、学习阶段、课程 ID、答案、日记、照片或录音。不新增游戏完成、录音、奖励或儿童画像事件。不采集 UTM 参数。

GA 后台需保持增强型衡量、Google signals、用户提供的数据、广告个性化及精细位置和设备数据关闭。事件和用户数据保留均设为 2 个月，关闭新活动重置期限；不影响 Google 的汇总报表保留。代码也明确关闭广告个性化和 Google signals。单页应用手动上报 `page_view`，避免与自动历史变化统计重复；Google 仍会产生会话和互动时间等基础数据。

## 如何看数据

- 报告 → 实时：核对最近访问与页面名称。
- 报告 → 互动 → 网页和屏幕：观察首页、小岛、学习、故事等页面访问。
- 报告 → 流量获取：观察来源网站和渠道。原始来源仅保留域名，不保留私人查询参数。

这是同意统计且能连通 Google 的访问样本。国内网络、内容拦截器、拒绝统计会造成漏计；会话 Cookie 可能使跨会话用户数偏高。不可把报表中的用户数当作真实家庭或孩子人数，也不能用访问量推断学习效果。Google 报表存在处理延迟。

## 发布与验证

`npm run check` 验证策略和项目回归，`npm run build` 生成网页包。Google 后台配置、代码构建、Cloudflare 发布、线上真实数据验收是独立步骤。

发布后在独立浏览器会话中验证：默认没有 Google 请求；家长开启后固定页面事件发往正确 ID；URL 参数不泄露；页面切换无重复；撤回后停止新增事件；隐私说明能再次开启或关闭。已经发送/进入发送队列的数据不因撤回自动删除。
