# 英语启蒙主线审计与调优 · 2026-10-17

## 结论与范围

产品已有 6 个主题章节、24 站课程、3 种可自定义的学习阶段，以及故事、复习和岛屿语境。主要问题是入口和反馈仍让“完成任务、收集能量”比学习主题更突出，现有课程与日常玩法之间的衔接不够清楚。本轮将英语启蒙放回主入口，以“学一点 → 岛上玩 → 故事里再遇见”为邀请路径。

这三步不是每日必做清单，也不是解锁条件。下一站仍按原课程进度开放，宝宝可以只听、指认、直接读故事、自由玩或退出休息。继续保留无需开口、无需书写的参与方式，不提高奖励、题量或停留时长要求。

审计基于当前源码、隔离的本地测试存档和实际界面。桌面浏览器布局与流程验收不等于 iPad 实机验收，也不证明儿童学习效果。

## 已实施的关键约束

- 学习首页使用现有 PNG 图标、简短中文和明显的主按钮，不添加新的大幅插画或 3D 资源。
- 学习主题与阶段一致，低龄阶段不会因为课程章节靠后就自动提高词汇难度。
- 已完成课程保留相关语境；场景到访只记实际播放的表达，不假定孩子说过课程目标句。
- 主题小游戏完成后引导至对应岛屿区域，不强制继续下一组。
- 新存档没有伙伴时，岛屿入口保留“去找伙伴”和退出通路；已有首次精灵球规则不变。
- 天气语音被关闭、页面切走或播放未完成时不写入听过记录；不新增定位、录音或云端儿童数据上传。
- 历史数据只有仍带明确 `saved` 来源标记的一次虚增曝光才被减去；不猜测无法确认来源的旧记录，也不清空真实学习历史。

## 下一轮应继续验证的内容

1. 亲子试用：宝宝能否从“学英语”自行进入，并在完成后理解“岛上玩”的邀请；不要以点选次数替代理解程度。
2. 语境深度：现有课程主题能关联故事和设施，但部分设施只提供通用表达。后续应按具体动作补情境对话，不能仅为“复现目标句”播放与画面不符的话。
3. 故事分层：现有双语共读可由家长陪伴；更长英文叙事不等于初学孩子能独立理解。后续按学习阶段提供简短听读版本，保持故事情绪与意义完整。
4. 学习效果：用间隔后的无提示指认、跨语境理解和自发使用观察进步；不把能量、收集数量、跟读录到声音或课程通关当成掌握。
