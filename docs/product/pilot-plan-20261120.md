# 方向 B：小范围试用两周 · 2026-11-20

负责人要求选收益最大的方向，选 B。本文是试用方案，不是已发出的招募。

## 为什么选 B

| 方向 | 投入 | 能得到什么 | 主要风险 |
| --- | --- | --- | --- |
| A 家庭自用 / 开源公益 | 最低 | 产品继续可用 | 不知道别的家庭用不用、有没有效，后续投入没有依据 |
| **B 小范围试用后再定** | **低：现有网页 + 家长中心记录 + 访谈** | **决定 A 还是 C 所需的证据** | 样本小，只能看方向，不能下效果结论 |
| C 走向产品化 | 高：账号与备份、隐私重做、内容持续供给、定价 | 有机会获得收入和增长 | 需要新建账号、付费服务和新的儿童数据处理方式，都要另批；在不知道孩子愿不愿意回来之前投入，风险最大 |

B 用两周和几乎零新增成本，回答 C 最关键的前提：孩子会不会自己想回来，家长看不看得懂、用不用得上。B 的结果无论好坏，都让下一步（留在 A 或进入 C）有依据。

## 已经准备好的

- 网页正式站点，新家庭有须知、交接卡和一分钟指引。
- 家长中心“学习概况”新增 **两周试用小结**：最近 14 天用了几天、时长、新走完的课、课程 / 隔天复习 / 小岛上第一次就选对的次数、在家试过的句子。只有次数和课名，不含名字、录音、照片、日记；家长点“复制小结”后自己贴进“联系与反馈”，不复制就不离开设备。
- 小结末尾附三个给大人的问题（在哪一步需要帮忙、有没有自发开口、谁提议玩）。
- 首日说明见 [parent-first-session.md](../trial/parent-first-session.md)，问题台账见 [issues-template.csv](../trial/issues-template.csv)。

## 试用怎么做

| 项目 | 安排 |
| --- | --- |
| 人数 | 5–10 个家庭，孩子 3–6 岁，尽量覆盖 3–4 岁和 5–6 岁 |
| 时长 | 14 天，不要求每天用 |
| 第 0 天 | 发首日说明；家长先读须知，陪孩子玩第一次 |
| 第 3 天 | 一句话问候：有没有卡住、有没有没声音 |
| 第 14 天 | 家长复制两周小结发回，加 15 分钟语音或文字访谈 |
| 不收集 | 孩子原声、照片、日记、完整存档、真实姓名 |

## 第 14 天看什么

| 问题 | 来源 | 判断 |
| --- | --- | --- |
| 孩子会不会自己想回来 | 小结“用了几天”；访谈“谁提议玩” | 一半以上家庭用了 6 天以上，且有孩子主动要玩 → 值得继续 |
| 一站是不是太难或太长 | 小结“新走完几课”；访谈“哪一步需要帮忙” | 多数家庭两周走完 3 课以上；同一处被 3 家以上提到 → 优先修 |
| 学过的词有没有用起来 | 小结“隔天复习”“小岛上用一用” | 只看方向，不当作学习效果 |
| 家长价值 | 访谈：看没看家长中心，在家试没试句子 | 多数家长没找到 → 家长入口要前置 |

## 结果怎样走

- **继续投入，准备 C**：多数家庭用了 6 天以上，有孩子主动回来，家长看得懂记录。下一步列出 C 需要另批的事项（账号、云备份、内容供给、定价、儿童隐私方案），逐项请负责人批准。
- **先修再试一轮**：用的天数少，但原因集中在可修的地方（卡点、声音、太长）。修完再找一批家庭。
- **回到 A**：普遍回不来，原因不在可修的地方。维持家庭自用与开源，停止增长方向的投入。

## 边界

- 招募和联系家庭由负责人进行；本仓库不自动发送任何消息。
- 素材公开分发授权仍未关闭（见 [试用准备记录](../trial/execution-20261018.md)）。熟人小范围试用前，负责人需自行判断是否可以；不作为公开招募。
- 5–10 个家庭的结果只用于决定方向，不写成“学习效果”或研究结论。
