# 我的小岛跟着学习路线走 · 2026-11-19

负责人确认的取舍：顶部只留一张今日任务卡和一个菜单；小岛区域按路线进度逐步点亮；一次完成全部改动。

## 规则（`src/lib/islandPlan.ts`，不写入存档，每次从课程记录推导）

| 规则 | 做法 |
| --- | --- |
| 区域点亮 | 路线到达某区域的第一课（当前、可学或已完成）时，该区域开放。新孩子只有营地区；之后依次是种植区（果园里的颜色）、休闲区（树果点心时间）、游乐区（小球轮到我）、海岸区（海岸小发现） |
| 未开放的区域 | 设施显示锁；点一下会播放开放它那一课的任务语音（已录好的配音），并显示“学到「…」，就能来…玩啦” |
| 玩法随区域开放 | 野餐、喂点心、歇一歇：休闲区；农场：种植区；玩球：游乐区；海边一起玩：海岸区；戳泡泡、一起跳：营地区 |
| 设施说的话 | 优先说孩子已经在这个地方学过的句子（多课时按天轮换，同一天不变）；没学过时保留原来的简单描述 |
| 玩法借用学过的话 | 喂食、摸摸、晚安、野餐、农场在孩子学过相应句子后，“我想说一句”改用学过的句子（最新的一课优先），没学过时保持原样 |
| 今日小岛任务 | ① 路线当前是“去小岛用一用”时：带伙伴去该课的地点，用上这句话；② 学完但还没在小岛用过的一课；③ 否则显示“下一站：…”，点一下回到路线 |

## 页面

- 顶部：公告、小岛生活（一起玩、野餐、装扮、联系作者、看风景）。删除名不副实的“今天的故事”。
- 任务卡和照顾请求、农场提示等共用左下角的提示位，同一时间只显示一个，优先级为：农场 > 野餐 > 照顾请求 > 今日任务（`homeHint`）。
- 修正：左下角提示位原来被底部导航挡住（照顾请求也看不见），现在位于“找伙伴”按钮上方。

## 顺带修复

“去小岛用一用”之前只认最近打开的那一课，且地点必须完全一致：第一章的小岛站在“软软睡垫”（`bed-`），永远无法完成；孩子开始下一课后，上一课的小岛站也无法完成。现在在某地点听到句子，会给所有已学完、在这里进行的课程记下“到过”。

## 第二部分：小岛生活玩法（2026-11-19）

负责人确认：伙伴用学过的话提要求、孩子听懂后点对；农场和野餐改用学过的食物词；小岛作答单独记为“小岛上用一用”。

### 同一个回合（`IslandAskRound` + `src/lib/islandAsk.ts`）

伙伴说一个学过的词或句子（已录配音），孩子从 3 张图片里点对的那张。点错：伙伴再说一遍，图片换位置；点错两次：亮出正确答案。没有扣分、失败或倒计时。图片只从孩子已经学完的课程里取，不考没学过的东西。每个回合记一条本机作答记录，来源为 `island:picnic / plant / feed / ball`，与课程作答分开。

| 玩法 | 改动 |
| --- | --- |
| 野餐 | 不再让孩子挑水果。点“请伙伴来野餐”，伙伴坐好后说出想吃的水果（果篮里、已学过的），孩子点对就分给它 |
| 农场种植 | 点空地后伙伴说想种的水果，孩子点对才种下。能种的水果随课程增加：树果点心时间（apple、banana）→ 谢谢你的帮助（strawberry）→ 我想要一个苹果（grapes、watermelon）。还没学过水果时点空地会说明要先学哪一课 |
| 喂点心 / 饿了的请求 | 伙伴说想吃的食物（已学过的），孩子点对后喂；如果是果篮里有的水果，就分一份果篮里的 |
| 轮流玩球 | 学完“小球轮到我”后，每一轮伙伴说 “My turn!” 或 “Your turn!”，孩子从伙伴和自己的头像里选该谁滚球；之前是伙伴的回合自动进行 |
| 戳泡泡、一起跳、歇一歇 | 不变。路线课程没有教数字，泡泡保持一起数，不做考查 |
| 装扮 | 不变，仍由路线上的小岛站逐级解锁 |

### 食物

农场作物从“蓝莓、桃子、草莓”三种树果改为课程里的水果词：apple、banana、strawberry、grapes、watermelon，图片与课程一致。旧存档在读取时折算：蓝莓 → 葡萄、桃子 → 苹果、草莓 → 草莓（数量相加，农田里正在长的、野餐回忆和陪伴小故事中的记录一并转换），可重复执行。界面文字“树果”改为“水果”；课程标题和已录配音不变。

### 家长摘要

“最近 7 天，孩子怎样作答”下新增一行“小岛上用一用”：只统计小岛回合，样本不足显示“记录不足”，不计入课程的“第一次就选对”。

### 验证

- 测试：`island-ask.test.ts`（未学不出题、每个选项都是学过的词且答案在其中、同一种子结果相同、野餐只要果篮里学过的水果、轮流玩球学完才出题、旧树果折算与重复执行）。全部 210 项通过。
- 浏览器（本地开发数据，合成）：喂点心（先错后对 → 记为“提示后完成”，分掉一个香蕉）；种植（错两次 → “看示范后完成”，种下香蕉）；野餐（一次点对 → “第一次就选对”，苹果 2 → 1）。截图 `output/island-restructure/06–08`。
- 未测：轮流玩球在浏览器里没走通。测试时浏览器面板被隐藏，伙伴走路的动画暂停，伙伴一直没有走到球场；逻辑由单元测试覆盖，需在可见窗口或真机上补测。
