# 以学习路线为核心的业务重构方案 · 2026-11-19

状态：**方案，待确认后分期实施**。

## 1. 定位与原则

啵啵岛是给 **3–6 岁孩子与陪伴家长** 的英语启蒙产品。孩子每天和小精灵伙伴沿着一条学习路线走一小段，在故事、小岛和生活里听懂、指认、尝试说出一点英语。

- **一条主线**：打开就是学习路线，今天该做的那一站最大、最亮，一个按钮就能开始。
- **一次一小站**：每站 5–8 分钟，每天建议 1–2 站，到点由时长管理温柔收尾。
- **听得懂、看得懂、找得到**：每一步只有一个主要动作；语音说到谁，画面就亮谁；不识字也能操作。
- **不评分、不扣分**：答错给提示，不出现“错”；允许只听、指认、用中文或手势参与。
- **学到的东西有地方用**：每站的词和句子，会在小岛设施、伙伴互动、故事和家里的小游戏里再遇见。
- **家长在旁边**：每站结束给家长一张“回家玩一玩”卡片；家长中心按路线展示进度与建议。

## 2. 现状问题

| 问题 | 现状 |
|---|---|
| 学习路线不是主线 | 首页是「今天的故事」（照顾伙伴短剧）；学习路线在「更多玩法 → 英语小发现 → 学习小路」第三层 |
| 入口平行、互相竞争 | 首页「更多玩法」6 个入口 + 学英语页 4 个小游戏 + 小岛底栏 6 个入口，孩子不知道该先做什么 |
| 奖励经济绕 | 两种货币：能量（做活动得）→ 5 能量换 1 个邀请果（兑换页）→ 去草丛邀请伙伴；每日能量上限、三类参与加成等规则孩子无法理解 |
| 学习和收获脱节 | 认识新伙伴、小岛装扮、小精灵长大，和学了什么没有关系 |
| 内容平行而非串联 | 课程 24 站已关联小岛设施、配套故事和家庭延伸（`station` / `story` / `homePlay`），但页面上是三个互不相连的入口 |

## 3. 新的主线：学习路线

### 3.1 路线结构

沿用现有 **6 章 24 站** 课程（`src/data/curriculum.ts`），把相关内容串成一条路线上的不同节点：

| 节点 | 内容来源 | 孩子做什么 | 收获 |
|---|---|---|---|
| 学习站（每章 4 个） | 课程单元 | 听词指认 3 个 → 情境短句 → 换个情境用一用 | 1 颗星，伙伴好感 |
| 故事站（每章 1 个） | 该章单元关联的绘本 | 听故事 / 一起读，点画面听词 | 1 颗星，故事收进书架 |
| 小岛站（每章 1 个） | 单元的 `station` 设施 | 带伙伴去小岛对应设施，用学过的句子完成一件事（浇花、轮流玩球、分享点心） | 小岛装扮一件 |
| 复习站（按到期插入） | 间隔复习（`learningProgress`） | 再听再认 3–4 个到期词句 | 1 颗星 |
| 伙伴站（每章末） | 章节奖励 | 送邀请果，认识一位新小精灵 | 新伙伴 |
| 长大站（隔章出现） | 伙伴好感 | 陪伙伴长大（可选择保持原样） | 伙伴长大 |

一章约 8 个节点，24 站课程展开后约 48 个节点，按每天 1–2 个节点约 1–2 个月走完一轮。

### 3.2 一个学习站的流程（约 6 分钟）

1. **开场**：伙伴出现在情境里，一句中文 + 一句英文说明今天要做的小事。
2. **听词指认**：3 个图片词，听音点图；答错给提示再试。
3. **情境短句**：看画面，选出合适的一句话（例如 Help, please! / Bye-bye!）。
4. **换个情境用一用**：同一句话换个场景再选一次。
5. **想说一说（可选）**：示范后可以跟读，也可以直接继续。
6. **收获**：得到星星，伙伴开心反馈；显示「回家玩一玩」家长卡（`homePlay`）。

按家长设置的学习阶段（听音探索 / 听词指认 / 日常表达）调整回合数和是否出现跟读、描字。

### 3.3 每天的节奏

打开 → 学习路线（今天的节点在正中、伙伴站在上面）→ 开始 → 完成 1 站 → 收获动画 → 可以去小岛陪伙伴玩一会儿，或继续下一站 → 到时长后休息页道别。

## 4. 各场景的新角色

| 现有页面 | 新角色 |
|---|---|
| 学习小路地图 `LearningJourney` | **新首页**：竖向蜿蜒的路线（多邻国路径样式），节点按 3.1 类型显示 |
| 今天的故事 `StoryHome` / 照顾短剧 `CareStory` | 并入「小岛站」；首页不再单独放一个故事 |
| 小岛学英语 `TaskBoard` / 课程 `LearningLesson` | 课程成为学习站内容；TaskBoard 不再作为入口 |
| 小游戏 `Practice` 与四类任务 | 成为学习站内的回合；已完成节点可「再玩一次」 |
| 故事屋 `Stories` / 绘本阅读 | 故事站打开绘本；书架只展示已解锁的故事，可随时重读 |
| 小岛 `Home` | 底部导航「我的小岛」：自由陪伙伴、小岛站在这里完成 |
| 草丛邀请 `Catch` | 伙伴站的奖励环节，不再需要先攒能量兑换 |
| 好朋友相册 `Dex` | 底部导航「好朋友」 |
| 能量 `Energy` / 换邀请果 `Shop` | **取消**：星星记录进度，邀请果由伙伴站直接发放 |
| 发现手册 `LearningNotebook` / 复习 | 复习站自动插入路线；手册保留在家长中心与「好朋友」页 |
| 小日记 `Diary` | 每章结束后的「说说这一章」，以及家长中心入口 |
| 家长中心 `Parent` | 按路线展示：今天学了什么、下次建议、家庭延伸卡、阶段设置 |

## 5. 导航

- 底部三个大图标：**学习路线**（默认）/ **我的小岛** / **好朋友**。
- 右上角：家长入口（长按 + 算术门槛，保持现状）。
- 任何页面最多一个主按钮；返回总是回到学习路线。

## 6. 奖励经济

- **星星**：每完成一个节点得 1 颗，路线上显示，章节累计；不能消费，只记录。
- **邀请果**：只在伙伴站获得并立即使用，孩子不需要理解兑换。
- **小岛装扮**：小岛站完成后获得，自动摆放（复用现有装扮奖励）。
- 取消能量、每日能量上限、三类参与加成和兑换页；时长管理与休息页保留。

## 7. 存档迁移

- 学习进度（单元完成、复习记录、故事进度）原样保留，路线节点由这些记录推导，已完成的单元直接点亮。
- 已有伙伴、好感、装扮保留；剩余能量按 5:1 折成邀请果，在下一个伙伴站一并使用。
- 旧的 `careStory`、`storyAdventure` 进行中状态在迁移时收尾，不丢伙伴回忆。

## 8. 分期实施

| 阶段 | 范围 | 完成标准 |
|---|---|---|
| P1 路线成为主线 | 路线首页（竖向节点）、学习站流程、底部三栏导航、今天节点高亮 | 新用户打开即进入路线，一次点击开始第一站；完成后回到路线并点亮节点 |
| P2 串起内容与奖励 | 故事站、小岛站、伙伴站、星星；取消能量与兑换；存档迁移 | 每章节点完整可走；旧存档进度与伙伴不丢失；测试覆盖迁移 |
| P3 复习与家长 | 复习站按到期插入、家长中心路线视图、章末小日记 | 到期内容出现在路线中；家长能看到今天学了什么和下一步建议 |

每个阶段独立可上线，阶段内完成测试、浏览器验收（浅色/夜间、iPad 横竖屏）后再进入下一阶段。
