## 1. 现在的问题

| 页面 | 现状 | 问题 |
|---|---|---|
| 学习路线 | 白底、一列圆点、一颗星一把锁 | 和多邻国是同一个样子；圆点不说明这一站会发生什么，孩子只能看到「下一个」 |
| 我的小岛 | 一张岛图，点地点弹出文字面板，面板里是一排文字按钮；另有「小岛生活」下拉菜单、文字任务卡、伙伴卡片上两排按钮 | 是给识字的人用的菜单；3.0 加的差事、聚会、组合指令都装在这些面板里，所以玩起来还是「点开面板做选择题」 |

## 2. 3–6 岁孩子怎么用屏幕

1. **不识字**：只靠声音和图画。任何必须读字才能继续的地方，孩子都会卡住。
2. **只会点和拖**：不会双击、长按、双指，也不会找藏在菜单里的东西。3 岁以点为主，4 岁以上能拖，落点要大、要能吸附。
3. **看见什么点什么**：屏幕上每样东西都该有反应；没有反应的东西是噪音。
4. **一屏一件事**：同时出现三个以上的选择就会乱点。
5. **一轮很短**：30–90 秒做完一件事并立刻看到结果；喜欢重复。
6. **不理解数值**：好感度、次数、进度条没有意义；看得见的变化（长大了、结果了、灯亮了）才有意义。
7. **没有失败**：做错了只是「再试试」，没有倒计时和惩罚。

## 3. 竞品里值得拿的和不拿的

| 产品 | 拿什么 | 不拿什么 |
|---|---|---|
| 多邻国 | 一次一小站、打开就知道今天做什么 | 圆点路线、连胜、经验值、红心、排行榜 |
| QQ 农场 | 种—浇—收的循环；每块地的状态直接画在地上；隔天回来有成熟的东西等着 | 偷菜、催熟、会枯死的作物、无限刷 |
| QQ 宠物 | 一只宠物是感情中心；宠物主动表达需要；吃、洗、玩、学是每天的事 | 数值条、生病和死亡带来的愧疚、打工赚钱 |
| 电子宠物 | 动词极少（喂、玩、洗、关灯睡觉）；照顾跟着真实的一天走；长大看得见 | 不照顾就受罚；呼叫提醒 |
| Toca / Sago 一类 | 没有文字；直接碰东西；点什么都有反应 | 完全没有目标（我们要有英语目标） |

关键的发现：**课程里教的句子，正好就是宠物会说的话**——I'm hungry、More, please、Thank you、My turn、Let's play、Good night、Help, please、I need a rest。所以照顾伙伴不需要另编一套玩法：伙伴用学过的英语说出需要，孩子用动作回应，这就是听懂。

## 4. 学习路线：一章一幅场景

见示意 1。

- **一章一页**：每章是一整幅场景画，像翻绘本；顶上是六幅小画表示六章，左右大箭头翻页。不再有白底和圆点。
- **站点是场景里正在发生的事**：
  - 今天这一站：一位伙伴站在空地上，头上的图画气泡画着这一站的东西，点气泡能听到这件事（就是课程里的 `situation`）；旁边一个大的开始键。
  - 做过的站：空地上留下做过的事（一篮果子、新朋友的帽子），和小岛上的「痕迹」是同一批图。
  - 没到的站：被云遮着，云里隐约看得见是什么；点一下云会晃一晃。不用锁。
  - 故事站是一本翻开的书，去小岛是码头的小船，新朋友是帐篷，说说这一章是野餐布。
- **自己的伙伴站在今天这一站旁边**，走完一站它沿着小路走到下一站。
- **去掉**：星星计数、邀请果计数放在页眉的做法（星星直接盖在做过的站上；邀请果在新朋友那一站出现）。
- **第二步（课内）**：听词指认从卡片搬进场景——东西就在场景里，点树上的红苹果；选句子变成伙伴遇到一件事、孩子替它选一句话。
- **美术**：现有 `learning-path.webp` 正好有四块空地，可做第一章；其余五章需要各画一幅（果园、游乐场、营地夜晚、海边等），用现有的画风流程生成。

和多邻国的区别：路线画的是「发生了什么」而不是「第几个」；进度是场景一点点热闹起来，而不是一串打了勾的圆点；没有连胜和经验值。

## 5. 我的小岛：推翻重做

见示意 2–4。

### 5.1 框架

| | 现在 | 重做后 |
|---|---|---|
| 结构 | 一张图 + 14 个地点 + 面板 | 总览（岛）+ 5 个场景（营地、菜园、野餐地、游乐场、海边），点地方就走进去 |
| 入口 | 下拉菜单、任务卡、找伙伴、伙伴卡片 | 伙伴头上的图画气泡；没有菜单 |
| 操作 | 在面板里点文字按钮、做选择题 | 直接碰东西：点它、把它拖给伙伴 |
| 文字 | 孩子要读 | 孩子不用读；小字只给家长看 |
| 一天 | 想玩多久玩多久 | 每天三件小事，做完全岛庆祝，然后可以说晚安 |

### 5.2 五个场景，各一个循环

| 场景 | 做什么 | 伙伴说的英语 | 用到的词 |
|---|---|---|---|
| 野餐地 · 吃 | 伙伴说想吃什么，把它拖到嘴边 | I'm hungry. / Apple, please! / More, please! / Yummy! / Thank you! | 食物 |
| 菜园 · 种 | 选种子、浇水、隔天来收；收的东西进野餐篮 | Help, please! / All done! | 水果、颜色、water、flower |
| 游乐场 · 玩 | 轮流滚球、放气球、上舞台 | Let's play! / My turn! / Your turn! | ball、颜色 |
| 营地 · 睡 | 挂月亮星星、关灯、说晚安；早上说早安 | Good night! / Good morning! / I need a rest. | sun、moon、star |
| 海边 · 找和迎接 | 找贝壳和小鱼；新朋友坐船来 | Let's go! / Hello! / Look at me! | fish、bird、water |

### 5.3 规则

- **学过的词变成岛上的东西**：学了 apple，篮子里才有苹果、菜园才有苹果种子；没学的是灰色剪影。孩子能玩的东西就是他的词汇量。
- **伙伴只说学过的句子**；没学过的需要只用图画表达。
- **到期要复习的词，由伙伴开口要**（现在的间隔复习逻辑不变，只是换了样子）。
- **路线的「去小岛」一站**：就是带着刚学的句子去对应场景做一件事（现有 24 件差事的内容保留，搬进场景里做）。
- **章节聚会**：全体伙伴在野餐地出现，保留。
- **不做**：数值条、饿了会生病、偷菜、倒计时、排行、每日签到奖励。伙伴的需要没被理会就自己过去了。
- **长大**：一起做过的事够多就长大（现有规则），不显示次数，只在快长大时身上发光。

### 5.4 保留和拆掉

- 保留（逻辑层）：`plays.ts` 的出题与到期排序、`errands.ts`、`parties.ts`、`farm.ts`、`islandAsk.ts`、存档字段、家长端的记录。
- 拆掉（界面层）：`Home.tsx` 里的设施面板、伙伴卡片按钮、「小岛生活」菜单、`IslandLivingPanel`、`IslandTaskCard`、`PicnicPanel`、`FarmPanel`、找伙伴；`IslandAskRound` 的选项按钮改成场景里的东西。

### 第 2 步 · 直接碰东西；吃和种（2026-11-22）

### 第 3 步 · 一天三件小事；玩、睡、海边（2026-11-22）

- **一天三件小事**：总览上方三颗星，每做完一件事（差事、聚会、任何玩法）亮一颗（存档 `daily.islandDone`，隔天清零）。第三颗亮起后回到总览，大家欢呼一次；之后伙伴不再冒气泡，只有学习路线在等的差事和聚会还会显示。场景仍可进去自由点、自由玩，没有锁。
- **邀请跟着时间走**（`rhythmPlay`）：早中晚的饭点，营地伙伴想吃；19:30 以后想睡。排在差事之后、其他心愿之前。
- **睡**：做完“准备睡觉”，这个场景天黑，伙伴换成打瞌睡的样子，说 Good night!，不再冒气泡；离开场景后恢复。
- **玩**（`BallTurns.tsx`）：游乐场前面有一个球（学过 ball 才有）。点它滚给伙伴，伙伴说 My turn!，滚回来说 Your turn!。没有对错、不计分，也不算三件小事之一。
- **海边**：有邀请果时，海边停着一条带果子气泡的小船，点它去迎接新朋友。
- 待定：三件做完后目前是“不再催，但能继续玩”。要改成真正停下（回休息页或只能看），再说。
- 验证：`npm run check` 通过（240 项测试）；浏览器里看过三颗星计数、滚球、海边小船、睡觉后的夜色。第三颗星亮起时的欢呼只有代码，没有在浏览器里触发过。
