## 安卓 APK（可通过微信传输）

测试包位置：`output/android/PokePal-0.1.0-test1.apk`。这是本地签名的调试测试包，不是应用商店发行版。首包约 445 MB（425 MiB），建议设备至少有 2 GB 可用空间，供接收文件、解包与存档使用。

1. 通过微信文件传输助手或设备支持的文件传输方式，把 APK 发送到安卓设备。
2. 下载完整文件。若微信不能直接安装，可在设备官方允许的文件管理器中打开。
3. 按系统提供的流程确认安装。若系统提示“不允许安装”“应用被管控”，需要设备厂商或家长管理入口允许；传输 APK 不会消除系统限制。
4. 安装完成后打开“宝可梦小小训练师”。模型、故事、23,264 条火山配音已在包内，第一次打开也无需联网下载。
5. 第一次跟读时由家长决定是否允许麦克风。拒绝后仍可以用“我说完啦”手动确认。跟读只检测开口时长并保存录音，不做发音准确率评分。

要求：Android 7.0+、Android System WebView 111+、支持 WebGL 2 / OpenGL ES 3 的图形环境。最低系统版本不等于流畅度保证；旧学习机的 WebView 可能独立于系统版本长期未更新。

## iPad / 浏览器 PWA

APK 无法安装到 iPad。iPad 继续使用正式构建 + 可信 HTTPS + Safari“分享 → 添加到主屏幕”。

1. Mac 与 iPad 连到同一可信局域网。
2. 使用设备信任、覆盖 Mac 局域网地址或域名的 TLS 证书，保存为 `certs/cert.pem`、`certs/key.pem`。如采用 mkcert，根证书安装与信任由设备所有者明确操作；不要把 CA 私钥传给设备。
3. 构建 `npm run build:ipad`，随后在有上述证书的情况下运行 `npm run preview:ipad -- --port 4173`。
4. Safari 打开证书对应的 HTTPS 地址。不要跳过证书警告代替可信 HTTPS。普通局域网 HTTP 不满足离线安装和麦克风要求。
5. 展开首页的“安装与离线准备”，保持页面打开，等“离线资源已就绪”，再添加到主屏幕。
6. 配音约 317 MiB，模型和页面还需额外缓存；建议至少预留 1 GB 空间。图标出现不代表离线下载已经完成。
7. 从主屏幕打开，关网络后退出再重开一次，确认模型、配音与故事能用。浏览器可能清理存储，重要存档应在家长中心导出备份。

普通安卓 Chrome 也支持同样的 PWA 流程。若使用 USB `adb reverse tcp:4188 tcp:4188`，正式构建应由 Mac 的 `npm run preview:usb` 提供，设备访问 `http://localhost:4188/`。这是 loopback 安全上下文，仅用于开发测试；设备需要已允许 USB 调试。初次安装和更新期间保持 USB 连接，缓存完成后再断开测试。

## 构建复现

- Node.js 22+、JDK 21、Android SDK Platform 36 / Build Tools 36。
- 当前机器 SDK/JDK 位于项目被忽略的 `scripts/.cache/android/`；也可指定 `JAVA_HOME` 和 `ANDROID_HOME` 使用自己的环境。
- `npm run android:apk`：校验配音 → Web 构建 → 准备原生资源 → Capacitor 同步 → Gradle 构建 → 输出 APK 与 SHA-256。
- `.build/android-web` 只保留活跃 MP3，不包含 PWA 的重复配音包，也不注册 Service Worker。原生版直接读取包内文件。
- 不需要在手机里安装 Chrome，也不依赖 Google Play 服务；仍需要设备提供可用且版本合适的系统 WebView。
