# 30 周年 × 风／波：海岛配色

## 官方视觉依据

- 30 周年专题：https://www.pokemon.co.jp/30th/ 。查看了当前主视觉：暖黄、浅蓝、浅绿、珊瑚橙的几何色块，以及红白周年标识。
- 风／波官网：https://www.pokemon.co.jp/ex/winds_waves/ja/ 。查看了薄荷绿的风、青蓝色的波以及海岛、天空和海洋背景。

下列为适配本产品的设计色值，并非官方品牌规范。保留手绘图标、圆润轮廓和纸张质感，以新的颜色角色替换大面积棕色、橄榄绿。

| 角色 | 色值 | 使用范围 |
| --- | --- | --- |
| 海岛浅蓝 | `#ECF8F8` | 页面背景、启动底色 |
| 暖白 | `#FFFEF7` | 阅读卡片、弹窗 |
| 深海蓝 | `#173F55` | 正文、标题 |
| 海洋蓝 | `#186BA6` | 学习、确认、下一步 |
| 明亮黄 | `#FFE36D` | 开始、能量与奖励 |
| 薄荷绿 | `#DDF4E8` | 选中、完成、自然活动 |
| 珊瑚浅橙 | `#FFE3D6` | 说一说、故事与陪伴点缀 |
| 夜海蓝 | `#102B42` | 夜间页面，阅读卡片仍然浅色 |

四类活动跨入口一致：听一听浅蓝、认一认薄荷绿、说一说珊瑚橙、写一写浅黄。图标与短标签继续承担识别功能，不依赖颜色区分。

## 实现与边界

- `src/island-village-theme.css`：集中 `--coast-*` 和 `--activity-*` 色值；通用控件、首页、学习、故事、图鉴、草丛、日记、礼物和家长中心。
- `TaskBoard.tsx` 为卡片补上实际类型 class；`Energy.tsx` 使用同一套活动色值，修复之前页面间色彩不一致。
- `App.tsx`、`index.html`、`vite.config.ts` 同步浏览器 / PWA 日夜背景。
- 不给宝可梦、食物和颜色教学图像添加滤镜；本轮没有重绘或替换 PNG 图标，不改变练习内容或状态。
- 不改变页面结构、触控区域、奖励规则或存档。

## 检查

证据目录：`output/qa/coastal-palette-20261017/`。

- 关键 9 组文字色对比度均 ≥ 4.5:1；主按钮 5.03–5.63:1，能量数字 6.73:1，正文 11.06:1。
- 浏览器平板 1024×768、手机 390×844；首页、英语主线、课程、故事、能量、四类练习卡与夜间模式。
- 深色模式通过开发工具模拟当地时间，并在结束时恢复；不代表 iPad 真机验收。
