# 小岛交互与弹层规则（2026-10-17）

面向 3–6 岁儿童：选择代表行动开始；只有真实选择需要点击。走过去、坐好、伙伴自己的回合由系统推进。消费树果前明确展示数量，能量升级仍保留可见价格和自主选择。

## 展示分类

| 优先级 | 对象 | 位置与规则 |
| --- | --- | --- |
| 0 | 存档恢复、到时休息 | App 级整页接管；原页面停止交互 |
| 1 | 家长验证、头像编辑、公告更新、捕捉结果、学习奖励、进化 | 原生 `dialog.showModal()` 顶层；背景不可点击，焦点留在对话框；关闭后恢复原位置。结果必须通过自己的按钮继续时不允许误点背景关闭 |
| 2 | 宝可梦卡片、找伙伴、一起玩、装扮、野餐、设施、区域选择、天气、小岛菜单 | 一个 `HomePanel` 状态；新面板替换旧面板。互动面板统一左下角，找伙伴仍靠近其入口，天气/更多靠近各自入口。面板出现时主菜单与被动提示让位；关闭在顶部，子页返回也在顶部 |
| 3 | 种植结果 | 左下角唯一提示位，短时显示，可关闭；优先展示刚操作的结果 |
| 4 | 跟随状态、未结束的野餐、照顾邀请、自动观察说明 | 按此顺序使用同一提示位，不同时渲染。打开互动卡后暂停被动邀请展示，关闭后重新判断当前需求 |
| 5 | 手势提示、日常操作帮助 | 没有更高优先级内容时出现；页面内帮助只在所属面板内部展开 |
| 局部 | 答题反馈、录音进度、保存错误、升级结果 | 留在产生它的页面/控件附近，不升级为全局浮窗。家长页 toast 不跨页面 |

平板/桌面左下角提示给右下主菜单留出宽度；窄屏提示移至主菜单上方。互动面板出现时隐藏主菜单，面板自身按安全区和屏高限制高度，内部滚动，关闭按钮始终可达。优先级实现见 `src/lib/homeOverlay.ts`；布局见 `src/overlay-layout.css`。

## 本轮简化

- 饥饿邀请 → 点一下，镜头选中伙伴并直接喂普通点心，不扣树果。
- 陪伴邀请 → 点一下，直接摸摸并反馈，不再绕到活动选择。
- 互动卡 → 喂点心直接完成；分享树果保留明确选择，选完返回主卡并展示反馈。叫声、晚安、图鉴收入“更多陪伴”。
- 野餐 → 默认当前伙伴或第一位已有伙伴，可展开换伙伴；选一颗树果后走到场景自动分享，实际到位才消耗一颗。到位前关闭取消，已分享不会再次扣除。空果篮仍可分享普通点心或去种植。
- 玩球 → 伙伴自动完成自己的回合，只有轮到孩子才需要点；两只伙伴一起玩时双方自然轮流。歇一歇到位自动开始。
- 保留主动选择：种什么/分享哪颗树果的现有约定、换伙伴、升级花费、进化形态、录音与照片提交。

## 验收重点

- 多个状态同时满足时左下角只能有一条提示；任何前台面板打开时不得显示它。
- 全局对话框打开时，岛屿自动镜头和新语音不启动；背景按钮不能被触摸或 Tab 激活。
- 分享重复回调、重进已完成野餐不能重复扣果；取消/未到位不扣果。
- 1024×768、390×844、844×390 下主要操作和关闭入口可见；没有跨屏横向溢出。
- 自动推进保留到位检查、页面可见性、保存错误与重复执行保护。
