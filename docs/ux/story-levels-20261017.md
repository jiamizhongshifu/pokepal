# 两本分层故事样板 · 2026-10-17

对应 roadmap P2“同一本故事适配不同阶段”，范围为《小球轮到谁》《小火龙心里的小风暴》，各 8 页。本批未扩展其余 8 本，不新增图像、不改变现有画面顺序。

## 产品行为

- 默认跟随家长设定的英语阶段：听音探索与听词指认采用短句版；日常表达采用完整原版。自定义阶段按短句配置 `phrases` 决定默认文本。
- 两版保留相同的冲突、等待/生气感受、选择、求助和修复，不把情绪简化成“立刻开心”。中文正文始终保留，英语重点词继续突出。
- 指认/选择模式可点画面上与实际物品对应的小喇叭听 ball、flower、sandcastle。点词先暂停正文和自动翻页，不叠播、不作为答题或独立理解证据。
- “短句/完整”决定内容；“听故事/一起读”决定翻页方式。家长在折叠的“陪读设置与记录”中可选择跟随阶段、短句或完整，孩子无需在入口重复选择难度。
- 语言版本偏好为全局故事设置，仅对这两本有分层的故事生效；其余故事保持原文。
- 原版书签继续使用原 `edition-2` 键；短句书签使用 `edition-2:short-v1`。切换时恢复各自位置，旧存档不丢失、不伪装成读完长文本。
- 同一故事的今日已读画面与参与奖励共享。听完或家长确认才计页；切换版本不重复领能量，不改变英语阶段，也不写独立掌握。
