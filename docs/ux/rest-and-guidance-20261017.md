# 休息页面与看图听音引导交付记录

日期：2026-10-17

## 修复结果

旧休息页使用 `captures.slice(0, 5)`，只显示前五个伙伴，导致新获得的宝可梦遗漏。已移除截断，展示全部拥有的伙伴，并把新朋友放在前面；伙伴较多时使用可滚动画廊，显示总数和继续查看提示。空存档不再虚构一个伙伴。

按设备本地时间区分：06:00–21:00 为日间休息，标题为“宝可梦要休息咯”，提醒放下屏幕、休息眼睛；21:00–次日06:00 保留晚安主题。沿用小岛已有的昼夜分界。确认休息后提供简短回应，不打开继续游玩的通路。提醒可重听或停止，离开页面即停止。

## 听得懂、看得懂、找得到

- 共享操作帮助加入简短图形步骤，并提供“找一找”，将实际可操作目标滚动到可见位置并高亮，不代替孩子点击。
- 已拥有的宝可梦使用回家陪伴的说明；故事、装扮、镜头帮助与实际操作保持一致。
- 学习选项高亮整组选项，避免帮助提示错误暗示某一个答案。
- 听故事时打开帮助，先暂停故事再播放说明，修复语音被打断后误报配音缺失的问题。
- 新增9条火山配音，未启用本地合成替代。

本轮覆盖休息页面及共享引导组件，并非对全应用每个独立流程的完整重新验收；幼儿实际理解程度仍需真实使用反馈。
