# 独立操作与轮流玩球 · 第一批交付

日期：2026-10-17。对应[产品路线图](../product-roadmap-20261017.md)首批 P1；本次完成频繁路径复核、玩球样板和野餐伙伴遗漏修复，不代表整份路线图完成。

## 交付行为

- 玩球先播放当前回合提示，再开始伙伴的动作。伙伴与宝宝各有头像，当前行动方高亮；宝宝的主动作是大图标“滚给伙伴”，可以重听，不自动替宝宝完成，也不按等待时间催促。
- 双击只触发一次传球。传球结束后的球位保留在接球方；前后回合连续，最后一轮不跳回。
- 两位伙伴自动玩球只记录实际听完的语言接触，不记作孩子动作、独立答题或因此发能量。宝宝主动完成且对应提示播放成功时，按原有场景参与规则记录；音频失败不伪造证据。
- 换活动、关闭、切页或进入后台取消该活动拥有的配音。加载失败仍可看图继续；伙伴未到位有重试与退出入口。
- 活动面板压缩为两方头像、当前状态、一个主动作与退出/休息。完成后以回岛为主，回忆和故事折叠为次要入口。
- 野餐不再使用网页版有限的当前场景居民列表，改为全部收藏；完整伙伴册支持头像翻页及家长辅助搜索。选中伙伴始终可见，空果篮也可以换伙伴并分享普通点心。
- 选择用的伙伴册显示“选这位伙伴”，不再误报“马上见面”，也不播放属于地图找伙伴的说明。
