# 现有素材版：故事到伙伴的完整流程

2026-11-12。本次仅修改网页源码与本地网页构建，未发布。

入口：故事屋、任务页新增「一起听故事，去认识新伙伴」；为精灵球收集能量时优先推荐苹果野餐。

使用已有《一颗苹果，谢谢你》八页场景与中英配音。点击开始后按音频完成推进；洗苹果段落可以帮忙扶篮子，也可以等待朋友完成。无需答题、逐页翻页或强制跟读。声音失败暂停重试；离开页面停止播放，返回从当前段落开头继续。完成后不连播。

故事结束 → 写入存档与能量 → 明确点击用 5 能量兑换精灵球 → 现有野外选择伙伴、投球 → 带伙伴回家。有现成精灵球时直接提供前往野外入口，不额外购买。

## 存档与奖励约定

- 保持 `SaveData.version = 1`。新增可选 `storyAdventure` 检查点和 `daily.adventureReward` 奖励记录，旧存档无需包含这些字段。
- 沿用原存档事务、失败恢复、备份、兑换与捕捉；不清空或重建伙伴、背包、花园、学习记录和旧故事书签。
- 每次播放器事件落盘；完成状态与奖励同一事务提交，保存失败沿用存档恢复界面，重试不会重新计奖。
- 苹果野餐每天故事奖励总额 5；与旧版共读共享每日故事参与额度。旧版先领取 2，野餐补 3；野餐先领取 5，旧版不再发 2。仍受所有活动每日 15 上限约束，三类参与奖励另按原规则计算。
- 观看完成即记一天参与；同一天的原三类奖励不重复增加参与天数或七日赠球。
- 重播、重复完成事件不再领取。跨日保留播放位置，昨天已结束的故事不会在今天打开时再次发奖，必须重播完成。
- 捕捉复用现有防重复伙伴、扣球与持久化逻辑，不自动投球或选对象。

这是现有绘本素材的连贯播放与收集闭环，并非新生成的逐镜动画。新原画、点心/种植/游戏更多剧集、家庭试用和网页部署仍待后续工作。
