# 和伙伴的小下午：现有素材版生活故事

> 当前故事版已按用户要求回退为本地测试，线上恢复旧版；见 [发布与回退记录](../../releases/story-home-20261112.md)。
入口：故事屋「和我的伙伴过一个小下午」，或伙伴面板「一起过个小下午」。从伙伴面板进入会优先带上该伙伴；已有未结束故事优先续播。

流程：分享点心 → 照顾农田 → 一起滚球 → 等待真实作物成熟 → 自动收进果篮 → 回家。默认只需确认分享点心和农田动作；滚球可主动推球，也可等伙伴自己演示，后续无强制翻页或答题。可以随时暂停或返回小岛。

## 真实状态

- 优先选择果篮中已有的一种树果，明确显示分享一份并扣除 1。果篮为空时使用原有免费普通点心逻辑。不会虚构树果库存；已选树果被别处用完时只能跳过，不静默改扣其他食物。
- 树果喂食沿用 `feedBerry`：实际更新照顾状态和友好度；普通点心沿用已有的 +4 友好度和饱腹逻辑。
- 农田优先安排成熟收获、缺水浇水、空地种植，最后才是等待正在生长的作物。不改变已有品种、种植时间，不重置农田。
- 空地种植橙橙果并一起浇水，复用现有免费种植规则。成长仍需真实 45 秒；滚球后尚未成熟则继续等待，也可以离开，下次回来继续。
- 收获仍是 2 颗、果篮容量仍为 999；满篮时留下作物，不丢弃果实。恢复时会核对地块编号、种植时间与品种，其他入口已经采走或重新种植的作物不受影响。
- 滚球使用已有 `rememberTogether` 记录一条 `ball` 陪伴回忆。不会另外生成积分、精灵球或未拥有伙伴。
- 新增可选 `careStory` 字段；旧存档无须迁移清空。动作结果与阶段一起通过现有 `commit` 持久化。连点、刷新、中断恢复不会重复消费、重复收获或重复记回忆。
- 原伙伴因进化不再使用旧 ID 时，可以带另一位已有伙伴续接当前阶段，已吃点心和已处理田地不重做。

## 素材与播放

复用现有角色原画、果园/花园/游乐场背景、点心/碗/水壶/小球道具和短句配音。新增情境字幕；语音使用已有「我饿了」「好吃」「水」「我们一起玩吧」等中英短句，并非新录制的完整旁白。动作使用页面动画；减少动态效果的系统偏好得到保留。

画面或声音加载失败暂停；切到后台或退出停止播放；重新进入需点击继续，避免自动扣除或自动开声。已有网页时长限制和存档错误恢复继续生效。

本次范围为本地网页实现和验证，未部署；不改动移动端、证书或原有用户媒体。
