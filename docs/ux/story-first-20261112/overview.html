01 / 为什么改变

宝宝需要理解故事，才能走进这座岛

当前问题

喂食、种植、游戏、学习和捕捉分布在多个页面与面板。宝宝需要先理解入口、功能按钮和下一步选项，才能把这些体验连起来。故事已有基础，但逐页阅读、选择和离开故事去做活动，仍打断了情绪与情境。

这次要做到

  • 每次打开，有一个清楚、温柔的故事邀请。
  • 用角色的行动和回应表达意义，非必要不做题。
  • 减少导航与选择，保留帮忙、表达喜欢和投球的主动权。
  • 完成任务 → 获得积分 → 兑换精灵球 → 捕捉伙伴，核心循环继续保留。

本轮范围：网页端交互与内容重构。首集完成后再扩展其他场景；不恢复 iPad / 安卓打包，不清空原有训练师存档。

02 / 宝宝的一次旅程

一个故事，带着体验往前走

自动讲述与可选参与相接；涉及积分消费和伙伴选择时，保留宝宝明确的操作。

  1. 01开始点一下故事邀请
  2. 02进入故事听、看，可选帮一下
  3. 03获得积分完整任务完成后记账
  4. 04明确兑换5 分换 1 个球
    点球才消费
  5. 05挑喜欢的伙伴宝宝自己决定
  6. 06投出精灵球轻轻一点或上滑
  7. 07一起回家陪伴或安心休息

没有操作时，故事仍会继续；到兑换或选伙伴时安静等待，也可以离开。不会自动消费积分、自动选择宝可梦或自动投球。

主要邀请

今天的故事

接着上次听，或进入一个适合今天的小故事。开始前不必挑难度、词汇或任务类型。

熟悉的陪伴

我的伙伴

看到已经认识的朋友，在具体生活情境里喂食、玩耍、种植和休息。

收集的乐趣

找新伙伴

保留选择喜欢的宝可梦和捕捉的期待。积分、精灵球与兑换关系清楚可见。

03 / 功能如何进入故事

把每一次操作，放回有意义的情境

现有功能新的呈现方式保留的主动参与
喂食朋友有点饿，洗好果实，递过去，收到真实的回应。可选点果实帮忙；朋友也能自行示范。
一起游戏小球滚过来，朋友邀请你加入，故事演出轮流与等待。可选点球回应，不必先选玩法和地点。
种植蔬果埋下种子、照顾它、见证成长，再与朋友分享收获。可选点种子或水壶；一镜头只邀请一个动作。
英语学习让单词和短句在动作发生时出现，并在后续情境再次遇见。愿意时跟说、指一指；默认无答案判定。
积分与兑换完整任务结束，积分收好；5 点积分换成一个精灵球。兑换需明确点击，不把计分弹窗插进情绪高潮。
捕捉与收藏遇见、打招呼、选喜欢的朋友，投球后一起回家。选伙伴与投球由宝宝决定，保留已有收藏。
  • 作为小训练师我想点一下就听见故事，这样不用记住很多按钮，也能知道发生了什么。
  • 作为喜欢伙伴的宝宝我想轻轻帮一下，让朋友回应我，这样我能感受到自己在故事里。
  • 作为陪伴的家长我想知道孩子听过、参与过什么，方便把一句话带回生活，而非把观看次数当作掌握。

04 / 第一集完整样片

先让一个小故事成立

《留给你的一颗苹果》

皮卡丘 × 伊布 · 从看见需要，到温柔分享 · 英语：Apple / Thank you

3′20″故事目标时长
  1. 00:00—00:45这里有你的座位皮卡丘铺好三个座位，伊布带来三颗苹果，邀请小训练师一起野餐。
  2. 00:45—01:40一起帮个忙水壶有点重，伊布开口求助。伙伴共同倒水，把苹果上的泥点洗去。
  3. 01:40—02:35留一颗给你伊布认真擦干小苹果，把它放到宝宝面前。皮卡丘将第三个座垫推近一点。
  4. 02:35—03:20我也被惦记着朋友自然说出 Thank you，一起吃点心、挥手告别。故事完整收尾后，再收好任务积分。

全程最多两次可选点物：点水壶帮忙倒水、点近处苹果帮忙擦干。无人操作时，角色自然完成，故事不断；宝宝不说英语也拥有完整体验。故事结束后可选择兑换与找伙伴，也可以离开；不自动连播。

故事奖励 / 新规则建议，尚未实现

一集完整故事任务 5 分；同一集每天只奖励一次，每日最多 15 分。重看不重复领奖，可选动作与跟说不影响奖励。5 分兑换 1 个精灵球，兑换仍需明确点击。

保留旧积分余额、精灵球库存、已拥有伙伴与图鉴收藏；七日赠球累计不清零。旧奖励记录与新故事记录的迁移、同日去重和持久化规则，见完整方案。

05 / 怎样判断有效

验证宝宝能否顺畅进入，而非点了多少次

以下均为首轮验收目标，尚无样片实测或儿童观察数据。
指标目标验证方式
开始负担主入口 1 次点击开始；故事中 0 次必需点击。从已进入产品的首页走查，同时验证开始手势能解锁音频。
连续体验无操作也能看完 3 分 20 秒故事；最多两次可选点物。无人操作播放；逐一核验动作等待与自动继续。
自主权未明确操作时，0 次积分消费、选宠和投球。在故事结尾与兑换、捕捉环节停留观察。
理解与情绪宝宝能从画面与声音跟上“一起准备—得到帮助—被朋友惦记”的关系。亲子观察与自然交流；不要求英文复述或设置理解考试。
可靠性重播、刷新和中断不重复发奖；旧收藏与库存完整。重复播放、断点恢复、存档迁移和奖励事务测试。

06 / 分四步推进

先做出完整体验，再扩展故事世界

  1. PHASE 01

    研究与规格

    本轮完成资料与源码核查、功能重构映射和首集文字分镜；视觉与节奏仍待样片。

  2. PHASE 02

    首集与播放器

    制作角色与动作样片，接入连续播放、两次可选动作和断点恢复，先让一集完整成立。

  3. PHASE 03

    收集与三个场景

    接通积分、明确兑换、捕捉与回家；用点心、种植、游戏三集验证核心行为。

  4. PHASE 04

    扩展与替换入口

    扩展角色动作库，迁移旧功能；结合亲子观察验收，明确尚未覆盖项，再发布网页。

07 / 样片中待确认

用看得见、听得到的样片作判断

产品 × 视觉
画风与角色表演。确认绘本质感、角色一致性、动作幅度与表情，是否能让宝宝看懂需要和回应。
产品 × 内容
旁白与停留节奏。确认 3 分 20 秒是否合适，英语出现是否自然，情绪落点是否留有呼吸。
产品 × 交互
邀请与自动帮助。确认两次可选动作的等待长度，让想帮忙的孩子来得及，也让只想看的孩子顺畅继续。

以 GPT Image 2.6 制作视觉资产是本提案的生产方向；动态图像仍需要分镜、动作设计、声音与播放器共同完成。本页不代表媒体已经生成或重构已经上线。
