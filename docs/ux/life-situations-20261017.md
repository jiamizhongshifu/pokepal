# 休息与求助情境样板 · 2026-10-17

范围：继续落实 roadmap P1 的“英语与行动对应”。本批补齐两个情境样板，不新增全局入口、不要求孩子跟读、不自动改变学习阶段。

## 已实现

- **我想歇一歇**：复用“一起玩 → 歇一歇”，伙伴到位后播放 `I need a rest.` 与简短中文邀请，随后自动安静陪伴 8 秒，结束播放 `Thank you!`。可以随时离开或换活动，无扣分、扣能量或好感惩罚。树叶提示仅播放一次，遵守减少动态效果设置。
- **帮忙收球**：玩球完成后出现可选入口。伙伴发出 `Help, please!` 请求，小收纳篮出现在安全空地；孩子轻点“收好小球”，小球移入篮子，伙伴播放 `Thank you!`。不会自动替孩子点，也不催促。
- **图声一致**：当前伙伴高亮、手掌主按钮、小球与篮子的过程图配合实际场景动作；不叠加奖励弹层。
- **真实证据**：完整听到邀请且动作完成后才记录场景行动。感谢语只记接触，重听不重复记账。均不记录独立掌握或跟读。求助不伪造新的轮流玩球回忆。
- **异常退出**：连点保护、离开停止语音、无伙伴回到认识伙伴入口；配音失败仍可看图完成，但不写入虚假听过记录。无安全放置点时不提供收球入口。
- **资源**：新增 4 句火山中文录音，英语沿用已存在录音。清单共 56,114 条，家庭离线配音仍为 256 包。

## 边界

这些是确定性语言情境，不是自由对话或自动评估英语能力。没有新增“必须先帮忙才可以离开”的门槛。实际 iPad 真机与亲子理解度仍需家庭体验；本批不声称证明教学效果。分层故事、阶段建议和完整数据迁移仍为下一阶段。
