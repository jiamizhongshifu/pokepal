# 页面屏效专项走查 · 2026-10-17

## 结论与范围

确认故事屋列表、学习小路、图鉴（含挑选伙伴）、宝可梦资料、能量小口袋、换精灵球、我的小日记共 **7 类页面**仍将关闭状态的“怎么玩”放在独立行。部分页面还叠加重复标题、筛选和说明，使核心内容位置偏低。

本轮只审计，没有修改产品代码、构建版本或部署。对当前本地源码运行 19 个页面/状态，分别检查 1024×768 横屏和平板之外的 390×844 窄屏，共 38 份 DOM 布局记录及截图。不是 iPad 真机复测，也不是生产版本全量验收。

测试使用独立 localhost QA 入口，关闭自动新手引导。初始存档会被 App 的异步加载覆盖部分字段，截图包含继承的测试进度；本报告仅使用最终可见布局，不依据奖励、伙伴数量等数据下业务结论。夜间主题来自应用按时间自动选择。草丛截图的异步宝可梦资源未完成加载，不能据此判断模型缺失或最终场景遮挡。

证据目录：`output/qa/page-space-audit-20261017/`，汇总尺寸见 `measurements.json`。以下坐标均为视口顶部起算的 CSS 像素，四舍五入；不含浏览器工具栏。

## 修复优先级

### P1 · 附带发现：学习小路当前关卡文字在夜间几乎不可读

- 位置：`src/page-hierarchy.css:39`、`src/island-village-theme.css:182`。
- 当前关卡背景固定为 `rgb(223,241,232)`，标题、单词和“现在这里”继承夜间文字色 `rgb(242,251,255)`。实际 computed style 确认文字 opacity 为 1。
- 对比度约 **1.12:1**，低于 WCAG AA 普通文字 4.5:1，也低于大字 3:1。这里是可开始的核心入口，不能以禁用态解释。
- 建议让浅色关卡背景和深色文字成对定义；同时复查夜间导航进度及其他浅色操作卡，不把本项扩大宣称为全站配色审计。
- 证据：[平板学习小路](../../output/qa/page-space-audit-20261017/journey-tablet.png)。

### P2 · 窄屏旧导航规则额外增加一行标题

- 位置：`src/child-ui.css:805-815` 的 max-width 600px 规则。
- 故事屋、学习小路、能量页把返回放第一行，标题强制放第二行；即使 `focused` 模式没有资源按钮，仍保留为资源按钮设计的两行布局。
- 实测导航高 130px，接着还有 Y=132–176 的帮助行。已整合工具的练习页导航约 70px。
- 建议按有无顶部工具、标题长度做布局，优先一行返回/标题/帮助。长标题允许有界换行，不缩小儿童按钮、不截掉关键文字。

### P2 · 写一写：帮助已整合，但辅助操作仍占书写空间

- 位置：`src/screens/TaskScreen.tsx:65` 及描写组件的响应式排布。
- 390×844 上，上方“换个游戏”单独一行，词卡加“听一听/看一遍/重写”占约 150px，再加笔划说明，实际书写框从约 Y=387 开始。
- 建议“换个游戏”降级为帮助中的备选；听词靠近词卡，演示/重写靠近画布形成一组工具。保留当前笔划方向和演示状态，不靠缩小画布提高表面屏效。
- 证据：[写一写窄屏](../../output/qa/page-space-audit-20261017/task-trace-phone.png)。

## 没有复现相同独立帮助行的问题

学习主页、小游戏选择、主题课程、听一听、认一认、说一说、写一写、发现手册和复习页，帮助已经位于顶部导航；答题进度也已整合。这些页不应再进行同一轮重复搬移。家长中心首屏使用顶部分类导航，没有单独帮助行。草丛帮助为绝对定位，不占文档流，因此不是同一种屏效问题。

38 份布局记录没有检测到横向溢出。这个结论不等于所有弹层、键盘打开、长文本、录音、完成态、捕捉动画或真机安全区域都通过。本轮未覆盖这些状态，也未完成全量无障碍/性能审计，不提供虚构的全站总分。

## 建议执行顺序与验收

1. 修复学习小路当前关卡夜间文字颜色，保证入口可读。
2. `/arrange`：统一上述 7 类页面的帮助插槽和窄屏导航。
3. `/distill`：逐页压缩重复引导与辅助信息，优先故事屋、日记、换球、挑选伙伴。
4. `/adapt`：调整窄屏写字工具区，保留足够画布和触摸热区。
5. `/polish`：检查长标题、首次展开帮助、夜间主题、横竖屏，最后再做真机回归。

验收重点：关闭帮助时不独占一行；核心内容紧接导航；底部操作不盖住内容；首次语音引导和业务状态不因移动组件失效。页面真实内容需要滚动时保留滚动，不以隐藏文字或缩小儿童触摸区域换取一屏。
