## 目标设备与体验矩阵

先为愿意支持的组合建立记录，不把模拟器当真机。设备发布继续暂停，只测同一个正式网页。

| 组合 | 网络 | 需要验证 |
|---|---|---|
| 中低端安卓 Chrome | 大陆家庭 Wi-Fi、至少一个蜂窝网络 | 首次进入/声音/场景帧率与发热/麦克风拒绝/后台返回 |
| iPad Safari 网页 | 大陆普通 Wi-Fi | 横竖屏、小屏阅读、录音权限、音频恢复、15 分钟后退出重开 |
| 桌面 Chrome | 海外普通网络 | 首屏、模型与配音加载、刷新存档、浏览器更新 |
| 首批家长实际使用的微信内置浏览器（如使用） | 对应手机网络 | 链接能否打开、音频/录音、引导“在浏览器打开”、反馈复制；未通过前明确排除 |

每个组合使用合成昵称/存档走一遍：

1. 打开固定网址 → 家长须知 → 选择训练师 → 认识首位伙伴。
2. 主线学一小组 → 看见能量到账 → 回到小岛听见相关英语。
3. 听故事、拒绝麦克风后继续体验；进入后台，再返回，检查声音不串页。
4. 刷新及重开 → 伙伴/能量/学习记录仍在；分别导出游戏和日记备份并恢复到隔离测试环境。
5. 更新 → 重开 → 检查存档连续性；网络失败时能够重试或安全返回，不要求清除数据。
6. 从家长中心找到帮助、暂停与数据删除入口；销毁仅限合成测试数据。

记录首个可操作时间、进入家园时间、首句声音等待、失败资源、设备发热/卡顿、家长必须代点的次数。当前没有跨地区真机数据，不给出“所有设备流畅”的结论。

## 故障处理与回退准备

- 当前生产：`c16f9231-1055-450b-b9b2-192de4cb3eae`；前一生产：`563bd993-11d1-47d7-834c-e91e7aade51b`。本轮仅读取部署列表，没有执行回退。
- Cloudflare 支持回到成功的历史生产部署，但这不会自动回滚浏览器 IndexedDB、本机存档或所有已控制的旧标签页。
- 前一部署不含本次家长说明，因此不能把它直接作为面向新家长的合格回退目标。应优先准备保留说明页面的修复版，或在重大故障时停止发新链接并按实际情况恢复服务。
- 需要立即暂停扩量的事件：存档丢失/覆盖、未经说明的数据上传、持续白屏、无法退出或计时限制失效。普通视觉瑕疵进入待修清单。
- 建议发布链路：检查 → 独立构建 → 完整产物验证 → 与生产清单比较旧资源 → 上传 → 正式域名/版本核验 → 合成存档核心流程 → 记录回退目标。GitHub 推送不触发当前 Pages 自动部署。

## 首批家庭的安排建议

R1–R5、R8 的对应门槛满足后，先邀请 5 个有家长陪伴的家庭；其间只修复阻塞，避免频繁加入新玩法。观察稳定后再扩到 10–15 个家庭、持续 7 天。

“只邀请 5 家”只是运营规模，并非网站访问控制：当前站点已公开，没有邀请码或白名单。若需要真正封闭试用，需另行决定访问控制及其给家庭增加的操作负担；本轮不擅自加登录。

首日只做“听一句 → 指认 → 伙伴回应 → 回岛再用一次”。后续关注是否自愿再听、是否少依赖家长解释、是否能找到返回与帮助。不要用答对数、能量数或游玩更久直接证明学习效果。

可用匿名家庭编号 F01…F05 记录问题；联系方式仅留在私密沟通渠道，不放公开 GitHub Issue。暂不需要新建大型客服后台、账号体系、付费系统、云端转写或广告统计。
