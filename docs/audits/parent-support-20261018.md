## 已实现

- 独立的 `/privacy/`、`/terms/`、`/feedback/` 页面：可以直接打开，不启动游戏，不读取 IndexedDB，不申请相机/麦克风，不安装游戏 Service Worker；支持浏览器缩放、手机阅读及系统深色主题。
- 首页、家长中心常驻说明链接；渲染异常和存档恢复页面也能打开反馈页，避免只能反复刷新。
- 第一次进入（以及旧用户尚未阅读此版本说明时）先展示家长摘要。未勾选不能继续；“暂不开始”不写阅读记录。确认只在 localStorage 保存说明版本，不属于家长身份认证或云端上传同意。
- 家长中心 → 应用维护 → 暂停试用：撤回本机阅读记录、回到首页；不删除训练师或已有进度，下次开始重新展示说明。清空本机数据也会撤回阅读确认。
- 数据说明区分本地存档/照片/录音、资源联网加载、Cloudflare 请求信息、家长主动发送反馈及系统键盘听写；说明最近 60 段跟读原声上限和其他本机数据保留方式。
- 明确游戏存档、日记原声、跟读录音需分别备份；修复网页版家长中心仍声称会向火山上传日记的问题。本地家庭版仍保留对应上传说明。
- 反馈默认只生成本机草稿；可选附上浏览器名称和主版本、屏幕档位、联网状态。复制与下载前可预览；不读取存档、照片、录音、日记、URL 参数、原始 UA 或错误堆栈。手动输入的内容需家长自行检查。
- 邮箱配置后可打开邮件草稿，由家长最终发送；不调用邮件 API，也不把唤起邮箱当作发送成功。
- 源码快照纳入三个 HTML 入口；发布产物校验增加独立页面及其引用资源检查。
