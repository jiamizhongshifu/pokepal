# 宝可梦避障与幼儿练习衔接优化

## 场景根因与改动

1. 旧实现根据目标点是否在圆形障碍内豁免碰撞，导致走向设施内部时设施本身变为可穿透。移除这种豁免，仅保留脚底已经在冥想石顶面的支撑例外。
2. 碰撞半径原来只由身高推算。现在在归一化模型时测量水平包围范围，覆盖转身所需半径；立绘使用实际宽高比。模型加载完成或装饰改变后重新检查站位。
3. 连续逐障碍推开可能把角色推回前一障碍。恢复落点必须通过全部相关障碍检查；有界搜索找到安全位置，正常行走只接受有效步进。
4. 蛇行不再自动等同于水中活动；显式水域目标和游泳保留水域规则。水中角色也避开浅滩岩石。
5. 长凳按实际朝向使用胶囊占地；补上沙坑边沿、玩球区球体活动范围及立柱。高大角色避开低树冠，低飞角色避开高树木；导航与角色碰撞使用同一体型和高度条件。
6. 角色停下后使用当前位置地形高度，避免被挪离旧座位后仍沿用旧座位高度。模型额外 scale 只应用一次。
7. 纯地形计算独立于渲染组件，避免导航把 Three.js 带进首页代码包。

## 练习流程

- 英语冒险：进入后自动示范 → 短暂停留 → 指认；答对后播放反馈 → 自动下一项。
- 听音探索：语音播放成功后留 2.4 秒观察时间，自动进入下一项；不要求逐项点“听过了”。一组完成后保留休息/去小岛的选择。
- 指认/复习：保留孩子实际选图，答对后的确认按钮取消。选错仍可重试，不自动猜答案。
- “慢一点”暂停自动衔接，“接着玩”恢复；重听会取消旧倒计时。后台页面不推进，离开组件取消待执行回调。
- 学习记录仍自动写入发现手册，收藏操作保留在手册内，不再占用每一题的操作区。
- 仅听语音不会写入独立答对记录；成功作答与帮助下完成仍分开记录。麦克风权限与开口、描写的真实操作保留。
- 入门听音不再同时出现“先听再点图片”的矛盾引导。
