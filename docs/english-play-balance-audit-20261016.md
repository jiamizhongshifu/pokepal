# 英语内容与玩法平衡审计 · 2026-10-16

## 结论

现有内容已经形成“认识词 → 短句 → 情境表达 → 岛屿相处”的骨架。当前优先级是把已有内容连起来、减少自动选题越级和无效重复，而不是继续堆题量。此次按当前源代码、内容盘点、业务回归和浏览器交互审计并修正；不以体验过课程、听过配音或完成动作代替“已经掌握英语”。

## 内容盘点

| 内容 | 当前数量与形态 | 平衡判断 |
|---|---|---|
| 课程 | 6 章、24 站；覆盖 31 个不同认图词、30 条不同目标表达 | 跨站重现是合理的，不能把重复次数当成掌握程度 |
| 认图词库 | 44 项，包括颜色、食物、动物、自然和日用品 | 岛上和生活中可看到的内容优先；不因加练自动引入无关词 |
| 跟读 | 44 条问候、需要、感受与相处短句 | 入门和进阶按家长设置选择；跟读允许只听，不做发音评分 |
| 情境表达 | 81 条附加词条，部分与基础词库可归一 | 适合在故事、设施中听见，不宜全部推入机械选择题 |
| 故事 | 6 本 × 8 页，共 48 页，每本 1 次可选互动停顿 | 礼貌、轮流、情绪、失落、诚实、守约；保留双语共读和真实感受 |
| 故事语言密度 | 每页约 6–14 个英文词，最长单句约 12 词（空格/标点粗计） | 可由家长共读；不等于零基础孩子能独立理解，不要求复述整页 |
| 奖励 | 每类首次参与 +2，体验三类 +1，上限 15；5 能量换 1 个通用球 | 保留多路径参与，不把开口、描字或答对作为获得伙伴的硬门槛 |

| P2 | 任务页的自由活动始终打开种植；故事入口不传递当前主题 | 随当前主题进入对应设施或活动，并打开已有配套故事。故事封面标出与当前冒险的关联；不锁其他故事 |

| P2 | 宝可梦本体多色，图鉴颜色标签未必等于宝宝从图上看到的颜色 | 颜色考题使用明确色块及现成颜色词配音，避免考图鉴分类知识 |
| P2 | 刚听到的词立刻到期；当天已独立纠正但仍标“需要练习”的词会被继续强推 | 新接触内容最早次日进入自动复习；日常选题尊重 nextReview。主动打开“再试试”仍可随时练习。情境型长表达留在手册，退出自动答题队列 |
| P2 | 同一设施配音同时调用两个记录接口；点野餐“听听谢谢”也能被记为行动；故事关键词与正文命中词可能重复累计 | 一次设施配音只记一次接触；每次设施到访最多记一次行动，重播只记听过；野餐重播不发行动能量；同页故事词归一去重。历史记录保留，不猜测性扣除 |
| P2 | 三个故事结束后缺少直接生活入口；任务的措辞仍容易被理解为必须做三类 | 补上种植、沙坑自由玩、小日记入口；任务改为“先选一个”，完成三类后突出返回自由玩。额外练习始终可选 |

## 各玩法承担什么，而不承担什么

| 玩法 | 英语学习触点 | 保留的玩耍空间 |
|---|---|---|
| 种植/收获/分享 | Help, please / Water / Two / I did it / Thank you 在对应动作中出现 | 点击就能进行动作；不先答题、不要求说出来才生长或收获 |
| 喂食/摸摸/休息 | Yummy / 感受 / Good night 等与照顾动作相连 | 关系和好感是陪伴反馈；不会把英语成绩当成关爱条件 |
| 一起玩球/安静坐坐 | My turn / Your turn / I need a rest | 可以选择玩或休息；动作参与与独立听懂分开记 |
| 捕捉/图鉴 | 名字与欢迎伙伴提供兴趣；偶尔进入听力趣味题 | 一个通用球即可捕捉想要的伙伴，不加英语考试门槛 |
| 任务/加练 | 小组练习，当前主题重现与间隔复习 | 可切换练习类型；可只听；额外内容按实际熟悉范围提供 |
| 故事/小日记 | 共读、重点词、可选回应；日记首先服务表达一天的感受 | 不考复述，不要求开心、道歉或公开经历；中文分享也有价值 |
| 闲置观察 | 当前镜头目标对应的简单英语输入 | 保留家长关闭/调频和手动接管；不自动计成独立答对 |

## 后续内容方向（原审计记录；实施进度见下方）

1. 在现有 24 站之间补少量短篇生活故事，优先“邀请、拒绝、求助、陪伴”，保持同一短句在两种生活情境重现；不优先增加大量互不相关的新名词。
2. 给种植和陪伴增加可选的双向回应，例如“要继续玩还是休息”；先保证孩子的选择会改变伙伴行为，再考虑增加英语提示。
3. 描字继续作为可选活动。当前没有完整的语音意识/字母音课程，不把字母描写包装成自然拼读能力；若扩展，应另做可听辨、可操作的小模块。
4. 在真实亲子使用中观察是否主动回到同一故事、是否更容易理解一条日常表达，以及是否愿意停下来休息。本次没有儿童实测数据，不能从题量、能量或代码检查推断学习成效，也不新增儿童行为上传。

## 参考原则与边界

British Council 建议幼儿活动短而多样、通过熟悉情境和自然重复接触英语，并允许孩子在准备好之前先听。我们据此采用小组练习、同主题重现和可选开口；具体题数是本产品的设计选择，不是研究规定的标准剂量。

- [Keep English sessions short and varied](https://learnenglishkids.britishcouncil.org/parents/top-tips/keep-english-sessions-short-varied)
- [How to start teaching kids English at home](https://learnenglishkids.britishcouncil.org/parents/helping-your-child/how-start-teaching-kids-english-home?page=7)
- [Speaking English at home](https://learnenglishkids.britishcouncil.org/parents/helping-your-child/speaking-english-home)

NAEYC 强调基于优势、游戏和情境的幼儿学习与观察。这里保留接触、辅助完成、主动行动、独立指认等证据区别；这些应用记录不能替代儿童发展评估。
