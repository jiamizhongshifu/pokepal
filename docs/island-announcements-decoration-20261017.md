# 小岛公告、装扮与海岛图标（2026-10-17）

## 公告与更新

- 首页和家园的「公告」共用已读状态，以发布 build + 最新公告 id 区分版本；已读状态独立于孩子存档。
- 新版本发布时构建生成 announcements.json，线上使用 no-store，离线包不把公告 feed 固定在预缓存中。断网仍可读随应用打包的公告。
- 公告轮询为可见页面每 5 分钟，重新聚焦/恢复联网也检查；弹窗里可主动检查。旧的边缘缓存响应不能覆盖较新的公告。
- 以后更新文案编辑 src/data/announcements.ts，新增条目放在数组首位，再按现有网页 / iPad 发布流程构建。无需单独修改用户已读状态。
- 公告使用原生 dialog，阻止背景点击；关闭恢复入口焦点。打开公告时停止互动语音，并暂停新的小岛对白。
- 网页更新显示「找一找 → 准备小岛 → 准备好了」，没有真实字节进度时使用不定进度；iPad 离线更新仍显示实际百分比、包数和下载量。失败可重试，成功后明确提供重开入口。

## 图标来源

- 80 枚现有 UI 图标经 Codex 内置 imagegen 重绘配色，另生成 16 枚装饰 / 升级缩略图。
- 主色：海洋蓝 #2684BD、薄荷 #72CBA7、明黄 #FFE36D、暖白 #FFFEF7，少量珊瑚色；保留教学食物的自然颜色。
- 原图、完整提示词、切图清单和哈希：output/imagegen/coastal-ui-v3/。
- 透明 PNG：public/icons/coastal-ui-v3/，256px；另保留 128px / 64px 导出。
- src/icons/generated.ts 引用新路径；原图标不删除，避免已打开的旧版本丢失资源。
