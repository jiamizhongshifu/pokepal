# 幼儿海岛 UI 改造与验收

日期：2026-10-15。对象：宝可梦小小训练师，3–6 岁儿童，由家长陪伴使用。

## 本次交付

统一欢迎、家园、四类学习活动、换球、草丛捕捉、图鉴、伙伴资料、家长中心、奖励/捕获/进化弹层和休息页。保留现有 PNG 图标、真实宝可梦素材、3D 场景、图鉴数据及离线配音；没有重新生成配音或改变已有存档格式。

- 主色采用浅海绿 `#eaf8f5`，白色实底操作面、海军蓝 `#163846`、深海青 `#087f87`，珊瑚色标出推荐活动。夜间改为深海蓝和高对比浅文字。
- 家园保留四个圆盘入口，五个机位收进“看看小岛”。取消数量徽标和普通按钮的持续跳动。
- 学习入口固定 2×2；中文是第一层，英文作为辅助。教学页仅保留返回、当前题目、语音重播及答案，去掉库存、家长按钮和重复英文页标题。
- 初阶草丛同时显示 3 位伙伴，高阶保留 6 位。点击目标的位置保持稳定；精灵球支持触摸点击、上滑和键盘触发。
- 图鉴每页 8 只，并提供“我的伙伴”。手机上翻页控件和返回入口保持可达，翻页后回到顶部；全部 157 个条目仍可访问。
- 换球显示可换状态、能量差额和成功文字反馈。资料页强调宝可梦图像、名称与“听听叫声”。
- 触控操作以 56–64px 起步，主要选择卡明显更大。小屏采用两列、单列及纵向滚动，不用整体缩小页面。
- 取消进化加速闪烁和全屏白光；支持 `prefers-reduced-motion`。安装版方向设为 `any`，不再强制横屏。

## 视觉依据与生图状态

已查看[《宝可梦 风与波》简体中文官网](https://www.pokemon.co.jp/ex/winds_waves/sc/)及[英文官网](https://windswaves.pokemon.com/en-us/)。官网描述海岛、海洋与自然生态，预定 2027 年发售。本次参考已公开的宣传视觉，不声称复刻未公开的完整游戏 UI。

《剑／盾》参考为[游戏菜单截图](https://archives.bulbagarden.net/wiki/File:SwSh_Menu.png)，本地参考位于 `output/imagegen/swsh-icons/references/swsh-menu.png`。采用圆盘图标、清楚的选中状态和简洁图文关系；没有照搬原菜单的成人向信息密度。

本轮通过 Codex 内置 imagegen 提交过家园、任务、教学、图鉴设计稿请求，但输出安全检查拒绝，类别为 `other`，没有返回可用设计稿。请求 ID：`e30f9794-d36b-4c1e-89b1-1a4023561fe6`。提示词及失败状态保存在 `output/imagegen/island-ui/brief.json`。

因此，本次交付是现有正式素材上的代码界面改造与浏览器视觉验收；没有新增生成图片，也没有完成“生成概念图与实现图逐像素对照”。此环节受工具返回限制，未虚报为通过。

## 视觉核对记录

首先用 Codex 内置浏览器查看并操作真实页面；随后用隔离的 Playwright 浏览器执行重复场景和存档测试夹具。测试用的 30 点能量、皮卡丘等数据仅位于隔离浏览器。截图以真实浏览器渲染为准，并使用 `view_image` 查看关键截图。

| 核对点 | 实现与结果 |
| --- | --- |
| 图标 | 沿用上一轮剑盾风格透明 PNG；主导航白色圆盘，草丛深色圆盘。未换成通用图库图标。 |
| 色彩 | 白底按钮与深色文字分离；夜间使用深色实底。修正夜间进度圆点不明显的问题。 |
| 信息层级 | 任务板为四种活动；教学中不显示库存；图鉴由长列表改为每页八只。 |
| 字体 | 中文标题 22–34px 为主；英文降为辅助；手机描红按钮保持单行。 |
| 触控 | 基础 24 个页面/视口组合未发现可见按钮小于 44×44px；主要操作通常为 56–64px 或更大。 |
| 布局 | 修复欢迎页横向溢出、手机资料图区域过高、描红按钮断行；长内容纵向滚动。 |
| 动态 | 普通目标和徽标静止，反馈时才有动效；进化不再高速切换或白屏闪烁。 |
| 文案 | 保留四类任务和四个主入口名称；有意新增“选一个，开始玩吧”“看看小岛”“我的伙伴”、翻页和兑换状态，教学语音内容不变。 |

无可用生成概念图，无法进行概念图原生尺寸/首屏文案逐项差异验证。对照对象为上述参考截图、明确的幼儿界面规范和实际浏览器画面。

## 验收范围

- `npm run build`：TypeScript 和 Vite 构建通过。既有大分包与大型 Service Worker 提示仍存在；本次未改资源缓存策略。
- 基础检查：12 个页面/活动 × 1200×900、390×844，共 24 组。图片无损坏、无页面脚本异常。欢迎页最初发现横向溢出，修复后复测宽度为 390。
- 补充视口：768×1024、320×568、844×390；补充深色教学、图鉴详情、换球、任务和家长中心。小屏长内容允许纵向滚动，无横向溢出。
- 真实点击：换超级球，能量 30→20、超级球 1→2；捕捉大岩蛇成功；进入资料并点击叫声；图鉴首末页、末页禁用、伙伴筛选与页码重置；手机翻页后 `scrollTop=0`。
- 真实画布操作：拖动产生笔迹，擦除后画布透明像素检查通过。
- 机位展开显示 5 个入口，选中海边后收起；家长弹窗可实际点击取消。
- 初阶 3 个、高阶 6 个遭遇目标；无球空状态正常。
- 家长设置、奖励与数据页无横向溢出。
- 进化组件使用隔离挂载夹具验证：选择雷丘、减弱动态揭晓、完成回调返回 26。此项是组件场景测试，不等同于完整 3D 家园进化流程验收。
- 最终构建产物：实际加载 `index-CSp6qmvF.css`；任务为两列、教学库存为 0、三个选项；图鉴每页 8 只，翻页后从 #009 开始且回到顶部；PWA 方向为 `any`。无页面异常、无失败请求。该次检查使用新浏览器上下文并禁用 Service Worker，避免旧缓存干扰；不作为离线升级验收证据。

详细机器输出位于 `output/playwright/island-ui/`：`screen-check.txt`、`interactions.txt`、`states-check.txt`、`remaining-check.txt`、`pagination-scroll.txt`、`build-final.log` 和最终构建验证 `release-check.txt`。
