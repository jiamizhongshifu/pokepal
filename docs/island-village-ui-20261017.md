# 小岛生活视觉迭代 · 2026-10-17

## 设计方向

以《动物森友会》的轻松岛居感、手作物品和自然材质为参考，形成项目自己的「小岛绘本」界面。参考入口：[Nintendo 官方岛屿介绍](https://animalcrossing.nintendo.com/new-horizons/explore/)。本次没有提取或复制游戏 UI 资源。

- 奶油纸面 `#fffbed`、暖棕文字 `#504637`、苔绿主按钮 `#53733e`、蜂蜜奖励 `#f6df9b`。
- 首页采用木牌标题、叶片标记和清晰的绿色出发按钮。
- 学习主线采用纸页与物品卡片；图鉴采用收集手册；故事屋保留可共读的书页结构。
- 岛屿导航保持右下角独立小按钮，没有恢复大面积底栏；互动卡片保留紧凑布局。
- 夜间采用森林色背景、浅色阅读卡片和明确的深色文字。能量数字保持深棕色。
- 图标先于文字提供线索，同一功能在不同页面沿用同一图像。保留大点击区、语音提示、短标签和完成状态。
- 不滤色教学图片；红/绿苹果仍明确区分，识字、计数、大小比较和人物形象语义保持不变。

## 已交付资产

通过 **Codex 内置 imagegen** 生成 4 张透明图标图集，切出 **64 个**独立图标。真实生成、透明 PNG，非代码绘制。256 px 版本接入应用，128 / 64 px 版本保留用于后续使用。运行时 64 张图共 **3,550,525 bytes（约 3.39 MiB）**，按页面实际引用加载。

- 导航与学习：耳朵、对话、图片、铅笔、书本、任务、图鉴、礼物、草丛、小岛、帐篷、麦克风、家、路牌、搜索、设置。
- 操作与反馈：返回、关闭、完成、播放、刷新、扬声器、手掌、爱心/空心、星星/空心、能量、锁、眼睛、音乐、精灵球。
- 自然与照顾：太阳、月亮、云、水滴、风、树、花、叶、食物碗、铲子、气球、靶心、拖动、庆祝、奖杯、闪光。
- 常用物品：球、帽子、海浪、伞、红苹果、绿苹果、香蕉、草莓、葡萄、蛋糕、牛奶、蛋、尺子、橡皮、火焰、泡泡。

其余动物教学图、属性图、训练师头像等沿用现有资产；宝可梦模型和已有故事画面未重绘。此次是全局界面语言及高频图标更新，不将 64 个新图标表述成全部既有资产已重绘。

源图、完整提示词、原始路径、SHA-256 和切图边界见 `output/imagegen/island-ui-v2/`。切图脚本 `scripts/slice-island-ui-icons.py` 通过连通区域归属保留完整轮廓，避免网格裁掉光线、叶片、泡泡等细节；透明边距至少 12 px，统一视觉占位。

- `src/App.tsx`、`index.html`、`vite.config.ts`：浏览器与安装启动底色保持一致。
- 本轮没有更改奖励规则、学习进阶、存档格式、捕捉规则和云端语音服务。
