## 2. T15 审计结果

代码审计【事实】：
- 全部外发：`/api/traffic`（本站基础访问量，只有固定页面名与次数，可关闭，DNT/GPC 时不发）；Google Analytics（只在正式域名 `pokepal-online.pages.dev`、家长单独同意、同意未过期（180 天）且版本为 2 时加载）；Chatwoot（仅家长主动打开客服）。
- 学习事件（开始 / 完成课程、复习、故事）只是固定名称，只在同意 GA 后发送；不带课程编号、答案、单词或作答分类。
- 本批新增的每题作答记录、“试过了”标记和复习间隔**只存本机**，没有任何发送路径。
- 同意记录包含版本号与时间；撤回会设置 `ga-disable`、清空待发队列和 `pokepal_ga` Cookie，每次操作都重新检查同意状态（含跨标签页撤回）。
- 小日记云端转写在网页版被禁用（`VITE_ONLINE`）。

本地运行检查（开发服务，localhost）【事实】：新用户、同意、撤回三种状态下，都没有站外请求，也没有加载 GA 脚本（本地域名本身就不允许收集）；同意和撤回都写入了 `{version:2, allowed, at}`。

【未测】正式域名上“同意后加载 GA、撤回后停止发送”的真实请求，以及“拒绝”状态的界面流程。真正测试会向 Google 发送一次真实统计，污染线上数据，需要负责人决定是否测试、用什么方式排除这次测试数据。

## 3. 内容与教学方面的限制

- **新情境的覆盖有限**：30 句情境短句里，只有 6 句出现在多课（Help, please! / Let's go! / More, please! / Thank you! / Let's play! / All done!），复习时能换到另一课的情境。其余 24 句和全部图片词没有第二套图片或场景；单词复习的干扰选项取自全部词库，和课上的选项不同，但图片本身相同。新增图片和场景需要人工审阅素材，本批没有生成。
- 复习候选仍用原有的固定间隔（1/3/7/14 天），没有引入自适应记忆算法，也不展示任何记忆分数。
- “第一次就选对”只表示没有用到应用里的帮助，不能说明孩子独立完成，也不能当作发音或语言能力的评估。
- 本版本之前的历史学习记录没有帮助信息，摘要里不计入，也不反推“独立正确”。

## 6. 未测项与风险

- 真机（iPhone、iPad、安卓）、真实儿童使用、屏幕阅读器朗读新摘要。
- 正式域名上的 GA 同意 / 拒绝 / 撤回请求（见第 2 节）。
- 跨日的真实复习：只用单元测试模拟了自然日间隔和时钟变化，没有在浏览器里真的隔天测试。
- 风险：课程中答错后选项换位置（T05），可能让部分孩子觉得“图片在动”；需要儿童观察确认。
