## 2. 审计后不改动的任务

**T14 低压力节奏**【事实】：
- 默认每日 15 分钟（`DEFAULT_SETTINGS.dailyMinutes`），到时进入休息页，白天和夜间分别用温和文案。
- 全部源码中没有“再玩就能获得”“错过”“集齐”“限时”“排行”类说法。
- 存档里有连续天数字段 `streak`，儿童界面不显示，只在家长中心的记录说明中出现。
- 课程每个回合即时保存，中途离开保留已完成的回合。
- 结论：无需改动。

**T10 音频状态**（代码审查 + 模拟）【事实】：
- 播放是“单路 + 令牌”：新的播放会先停止当前声音，过期序列不再续播；`stopSpeech` 让所有在途序列失效。
- 模拟“快速点十次”帮助里的“听一听”：任意时刻最多 1 路声音。
- 播放中点“返回”：声音立即停止（1 路 → 0 路）。
- 【待核】真实 iPad / 手机的冷启动、系统静音、自动播放限制、后台切换、麦克风拒绝后的替代路径，都需要真机，本批未测。
