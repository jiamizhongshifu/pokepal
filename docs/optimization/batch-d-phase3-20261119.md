麦克风释放：跟读离开任务页和应用进入后台时调用 `releaseMic`；绘本与日记的录音器在组件卸载和页面隐藏时停止并释放麦克风。

说明与实际不一致处（已修正）：
- 隐私说明写日记“直到主动删除”，但之前没有单篇删除 → 新增删除入口，说明写明删除位置。
- 隐私说明和家长中心写“跟读原声可在学习概况中另存”，但之前只能回放 → 新增“保存到设备”。
- 隐私说明没有提到绘本“我来说一说” → 新增一条：只在当前页面回放、不写入本机存储，刷新或离开即丢弃。

其他修改：跟读录音的“写入 + 删最旧”改为同一个事务，写入失败时不会出现超过 60 段或只删一半的情况。删除需在 6 秒内对同一按钮点两次。

## 2. T12 存储与异常恢复

审计结论（已有机制）【事实】：
- 写入带修订号，另一窗口改过就报“冲突”，不覆盖。
- 同一时间只允许一个窗口持有存档（第二个标签页显示“游戏已在另一个窗口打开”）。
- 读取失败不会用空白存档覆盖；写入失败时保留当前快照，可重试，且在恢复前禁止继续修改。
- 课程、伙伴等最终奖励在存档写入成功后才显示（`commit`），退出再进不会重复领取。
- 导入前校验，并先备份为“导入前的存档”。
- 页面隐藏和关闭时立即写入待保存的内容。

本批新增：
- 恢复页（写入失败 / 读取失败）加“给大人”折叠：写入失败时导出当前页面里的进度（可在家长中心重新导入）；读取失败时原样导出本机存档用于排查（明确说明不能直接导入，原存档仍在）。导出都去掉头像照片；录音和日记本来就不在存档里。另显示一行诊断（问题类型、存储用量、是否持久保存、是否联网），不含存档内容。
- 家长中心“备份与恢复”明确写出：清除网站数据、卸载浏览器、无痕窗口或换设备都会丢失存档、录音和日记，运营者无法找回；并显示存储用量和浏览器是否承诺持久保存。

## 3. 验证（合成数据，开发浏览器）

| 场景 | 方法 | 结果 |

| 跟读单条删除 | 写入 2 段测试音，在家长中心删除 1 段 | 第一次点按钮变为“再点一次删除”，超过时限自动复原；确认后只删该段，计数 2 → 1，数据库同步。截图 `t11-recording-delete.jpg` |
| 日记单篇删除 | 写入 1 篇合成日记（含 1 段测试音） | 两次确认后删除，数据库 1 → 0 |

| 存档损坏 | 写入一条不合法的作答记录后刷新 | 显示“暂时没能读取进度”，损坏的存档仍在、未被覆盖；恢复原存档后点“重新读取进度”正常进入。截图 `t12-load-failure.jpg` |
| 多标签页 | 第二个标签页打开 | 显示“游戏已在另一个窗口打开” |
| 测试 | `scripts/tests/save-export.test.ts` 3 项 | 导出去掉照片、不改原对象、仍可导入；损坏存档原样导出；未知用量显示“未知” |
