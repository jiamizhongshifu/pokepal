## 关键修复

首次创建训练师原先通过延迟保存进入家园；离开页面过快时可能丢失新建档案。现在等待持久化完成后才进入，并拒绝写入期间的重复创建；已有训练师不会重复领取见面精灵球。模拟 300ms 写入延迟验证通过。

`npm run release:prepare` 先读取真实生产版本和资源清单，按版本 ID 与源码指纹定位本地生产产物；不会将连续未发布构建误认为线上版本。校验旧文件、不可变文件冲突及目录范围后，保留旧页面需要的资源，并再次完整验证。缺少旧版、文件冲突或源码变化会阻止继续。`npm run release:publish` 是独立的显式上传入口，要求干净 main，准备后再次核对提交，构建不会自动上传。
