## 给家长

这是一款正在试用的 3–6 岁英语启蒙网页。我们希望孩子在陪伴伙伴、看故事和玩小岛时，愿意听一点英语、找一张图片、试着表达。参与记录不等于熟练掌握；跟读不会给发音打分。

- 免费试用，无内购。需要联网；目前没有账号和跨设备自动同步。
- 请固定使用 <https://pokepal-online.pages.dev/>，同一设备和浏览器继续体验。不要把预览网址当作日常入口。
- 第一次由家长阅读[试用须知](https://pokepal-online.pages.dev/terms/)和[隐私说明](https://pokepal-online.pages.dev/privacy/)，选择适合孩子的阶段与时长。建议先体验 5–10 分钟，随时可以停。
- 可以一直使用预设头像；不必提供真实姓名或照片。拒绝麦克风后仍能听故事和点图片。
- 开始只做一件事：认识一个伙伴 → 在“学英语”玩一小组 → 回小岛再听见一句英语。不需要做完所有任务或集满奖励。
- 刷新、更新或换设备前备份重要内容。游戏存档、日记和原声的备份范围不同，见家长中心“应用维护”。
- 首批设备支持范围由实际测试后填写；暂不承诺所有手机、微信内置浏览器或大陆/海外网络都流畅。
