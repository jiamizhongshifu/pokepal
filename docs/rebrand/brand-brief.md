# 品牌与界面规范（草案）· 2026-11-18

## 方向

- 去掉宝可梦 IP：名称、角色、精灵球、图鉴、叫声、3D 模型、图标与绘本插画全部替换为原创内容。
- 交互参考多邻国的**做法**，不复制其**外观**：大而可按的厚底按钮、明亮平涂、粗圆字体、清楚的学习路径、角色用表情给反馈、即时的对错横幅。
  不使用多邻国的品牌绿 `#58cc02`、Feather 字体、猫头鹰或其人物造型与比例，避免商业外观（trade dress）相近。
- 角色改为 16 种原创动物小精灵（动物 + 自然元素，7 种属性，各 3 个成长阶段），2D 平涂插画，每只都有表情与动作套图；小岛改为插画场景，去掉 3D 依赖。

## 字体

- 拉丁字母：Nunito（SIL OFL，可自托管），标题与按钮 800，正文 600。
- 中文：系统圆润黑体优先（PingFang SC / HarmonyOS Sans SC / Noto Sans SC），标题 800、正文 500。
- 3–6 岁阅读：正文不小于 18px，英文句子 24–30px，按钮文字 18–22px。

## 组件原则

- **厚底按钮**：圆角 16px，底边 4px 用按下色；按下时下移 4px、底边归零。最小点击区域 56px（儿童手指）。
- **卡片**：白底、2px 线灰边框、4px 底边，圆角 20px。
- **对错反馈**：答对整条青色横幅 + 精灵欢呼；答错珊瑚色横幅 + 精灵给提示，不出现「错」字和扣分。
- **学习路径**：单列蜿蜒的圆形关卡节点，当前节点由精灵站岗，完成后变成徽记。
- **角色反馈**：引导、等待、答对、需要帮助、休息提醒都由向导精灵的表情完成，文字只做辅助。
- 动效：弹跳 120–200ms，尊重 `prefers-reduced-motion`。
- 无障碍：文字对比度 ≥ 4.5:1，图标按钮都有中文 `aria-label`。

## 角色画风（2026-11-18 定稿）

参考你提供的多邻国 × 宝可梦联名宣传图的**画法**，角色全部原创：

- 平涂矢量，形状几何但圆润：圆角梯形、椭圆、斜切圆角矩形和不对称团块，略带棱角、不追求完全对称。
- **完全没有描边**，只靠色块区分形状；每种颜色一块硬边深色阴影，偶尔一块浅色高光；无渐变、无纹理。
- 高饱和明亮配色。
- 脸：大白眼，常常一只略大，瞳孔偏向动作方向；眉毛、眼皮用实心色块；嘴是实心形状，里面有深色和舌头。
- 四肢是粗短圆头的胶囊形，不用线条。
- 动作夸张有弹性，斜向构图，剪影一眼可辨。
- 画面里不出现文字。精灵以真实小动物为原型、加一个自然元素作标志特征；原型避开宝可梦 151 的代表物种，不用猫头鹰，每种定稿前与各代宝可梦和多邻国角色逐一比对。

生图规范与造型描述已入库：`scripts/art/style.txt`、`scripts/art/sprites.json`，批量生成用 `scripts/art/generate.mjs`（会为每张图留下提示词、参考图、模型和时间记录）。画风参考图 `output/rebrand/style-reference.png` 与生成的图片保存在本地 `output/`，按开源范围不入库。

已知修正：啵啵必须是圆泡泡（不是水滴，水滴是「滴滴」）；墩墩是贴地的扁圆鹅卵石（不是海豹或鱼）。
