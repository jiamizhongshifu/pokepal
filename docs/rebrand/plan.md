# 原创化与界面重构计划 · 2026-11-18

目标：去掉全部宝可梦 IP，换成 16 只原创小精灵与原创世界观；界面按多邻国的交互原则重做，使用自有配色、字体与角色。规范见 [brand-brief.md](brand-brief.md)，角色设定见 [creatures.md](creatures.md)。

| --- | --- | --- |
| 角色数据 `src/data/pokemon.json` | 388 只，含官方图鉴文字 | 换成 `src/data/sprites.ts`（16 只原创），删除图鉴文字 |

## 玩法用语调整

- 「捕捉 / 精灵球」改为「邀请小精灵来岛上做朋友」：用自己种的树果邀请，不再有投掷和球。
- 「图鉴」改为「好朋友相册」；稀有度星级保留为「认识程度」。
- 「训练师」改为「小岛主人」；进化改为「长大一点」（换装或长出新的小部件，不改变物种）。

## 分阶段

1. **定稿（当前）**：产品名、配色字体、16 只精灵设定、试点图通过评审。
2. **美术生产**：用 Codex 内置生图按统一风格生成全部角色图（约 208 张），再做场景、绘本、图标；去背景、统一尺寸、建立 `public/sprites/` 清单与授权记录（生成工具、提示词、日期）。
3. **数据与玩法**：新增精灵数据模型，迁移玩家存档（旧宝可梦 ID 映射到新精灵，保留进度与能量），删除宝可梦数据和 3D 资源，改写文案。
4. **界面重构**：建立设计 token 与基础组件（厚底按钮、卡片、反馈横幅、路径节点），把 `src` 根目录的 20 个 CSS 文件收敛到 token 体系；首页、学习路径、绘本、练习、日记、家长中心逐页迁移。
5. **配音**：按新角色重新收集台词并合成（先统计条数与费用，再确认执行）。
6. **验收与发布**：测试、真机、隐私与开源说明更新；正式站发布需单独确认。

## 风险与建议

- **线上站点**目前仍在提供宝可梦角色图、3D 模型与叫声。原创版本上线前，是否先下线相关资源由你决定。
- **GitHub 仓库**中的 `src/data/pokemon.json`（含官方图鉴文字）和提取宝可梦 GO 资源的脚本已公开。原创化后建议删除；如需彻底移除，还要考虑 Git 历史，这一步需单独确认。
- AI 生成图的权属：保留每张图的生成记录；发布前人工检查是否与已有角色相似。
- 多邻国参考只取原则：评审时检查配色、字体、角色是否与多邻国过于接近。
