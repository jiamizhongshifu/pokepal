# 宝可梦小小训练师（PokéPal）

面向 **3–6 岁儿童与家长**的英语启蒙应用。让孩子在宝可梦小岛里听见英语、看图理解，并通过故事和照顾伙伴自然再遇见熟悉的表达。核心体验是 **听得懂、看得懂、找得到**，允许只听、指认、尝试表达和随时休息，不强制开口或书写。


## 陪伴的产品原则

- 每一种心情都可以被表达：不要求孩子保持开心，不用“乖不乖”评价分享。
- 小日记不计分、不发任务奖励；允许跳过、休息和稍后继续，不把表达变成作业。
- 让孩子关注生活的小事、自己的感受，以及人与伙伴的关心；提问保持开放，不预设经历或要求感谢。
- 保留孩子原话，家长可核对转写；不会把系统提问或虚构经历写进孩子的故事。
- 学习与成长融入陪伴和尝试，已有“不扣错题能量、离线不增加照顾负担”的规则继续保留。

## 英语学习体系

家长可在「设置 → 宝宝的英语学习阶段」选择听音探索、听词指认、日常表达，或独立调整词汇范围、认词起点、短句参与方式、选项数和复习组量。可随时放慢，已有进度保留；[阶段说明与后续扩展约定](docs/learning-stages-20261016.md)。

### 由认词走向生活表达

| 章节序号 | 主题 | 目标与例子 |
|---|---|---|
| 1 | 认识我的小岛 | 打招呼、颜色、点心、昼夜；先听见词，再指认图片 |
| 2 | 一起照顾伙伴 | 照顾植物、轮流玩、海边发现、礼貌请求；Help, please! / My turn! |
| 3 | 说说我的小世界 | 心情、感谢、邀请、完成约定；I'm happy! / Thank you! / All done! |
| 4 | 我会照顾自己 | 口渴、要苹果、吃饱拒绝、休息；I'm thirsty. / No, thank you. |
| 5 | 心情都有名字 | 难过、生气、再试一次、陪伴与独处；I feel sad. / I need some space. |
| 6 | 我们是好伙伴 | 加入游戏、道歉与修补、交接轮次、收拾；May I join you? / Let's tidy up! |

每章 4 站。原有前 12 站每站 4 个回合；新增后 12 站每站 5 个回合：**3 个词语回合 → 表达情境 → 换个情境用一用**。旧完成记录保持有效，中途退出可以续接。

当前基础词库有 **44 个图片词、44 个功能句和 A–Z 字母**，另有宝可梦名称及动态活动描述。新增课程复用熟悉词汇，增加 16 个日常表达与 24 道情境选择题，不依靠一次引入大量生词增加难度。

### 学习与小岛衔接

- 听辨、认图、跟读、描字共用当前课程与到期复习的选词计划；优先带出一个需要复习的词。课程完成后推荐下一站，仍可主动重玩。描字优先选择同组可具象展示的词。
- 家长选择的学习阶段与自定义策略在全部章节有效，不按章节自动升难。说、写均可自选，不影响三类参与目标。
- 完成后可“回小岛玩一玩”，前往对应设施与已有伙伴互动；任务页也可直接打开当前主题的配套故事。设施台词描述实际活动，不用课程句子覆盖场景。
- 日常和加练选题均遵守家长设置的难度；选图模式的普通听力包含两道主题题和一道趣味题；听音探索先陪听当前主题词。加练仅扩展当前小组、到期内容与已接触内容，不为凑数量填入陌生词；完成三类参与后突出自由玩入口。
- 家园环境英语描述实际活动，例如 `Look! Pikachu is eating.`，可在家长中心关闭或调节频率。
- 每站提供亲子生活练习；允许用指认、手势和中文参与，不强制开口，也不要求孩子必须分享、必须开心或立即原谅。

### 复习、跟读与描字

- **生活选择**：一起玩时可直接转为休息，伙伴到达后自动安静坐坐；可随时转回玩球或离开，离开会释放活动占位。选择不要求先答题或跟读，读故事和仅点选不会冒充独立掌握。
- **发现手册**：统一大小写、结尾标点与稳定词条 ID；64 页故事重点、十个主表达与设施台词均可归档。故事词组复习重播已有完整语境录音，不冒充独立词汇测验。
- **再试试**：记录答错后需要帮助的内容；中文帮助、答案预览、文字情境选择与独立英文指认分开记录。历史无法分辨帮助的成绩保留为旧练习记录，不继续标为独立掌握。
- **间隔复习**：新接触内容最早次日进入自动复习，独立答对后的复习间隔按 1、3、7、14 天推进；同一天反复作答不会增加间隔等级。自动选题尊重到期时间，情境型长表达留在手册重听，不自动变成选择题。
- **说一说**：示范后检测开口并支持录音、回放；不做语音转写或发音准确率评分。麦克风不可用时可手动确认“我说完啦”，也可在听完示范后选择“这次先听听，继续”；不按声音大小或时长给星级。
- **写一写**：笔顺自动演示一遍后隐藏，落笔可打断，也可主动点“看一遍”；提供起笔位置、方向和分笔提示，允许手指偏差与抬笔续写；不把描字作为低龄孩子参与其他学习的前提。

没有全局固定双语字幕条。故事逐页保留中英文文字；练习卡片按任务需要显示英文和中文提示，语音提示可在家长中心选择双语或英文。

故事奖励按当天完整听读或家长逐页确认结算；仅翻页不结算。同类小游戏、同一课程主题、重复阅读或设施重听在同一天不会重复发能量；不同课程主题可各结算一次，仍受每日上限限制。课程、词条、宝可梦、好感与已获得奖励保持兼容。场景到访仅标记“到过对应场景”，不会自动把 Sorry / Help, please 等课程目标记为使用；照顾后的跟读改为“我想说一句”自选入口。

相关实现：`src/lib/participation.ts`、`src/data/learningLexicon.ts`、`src/data/curriculum.ts`、`src/data/learning.ts`、`src/data/words.ts`、`src/lib/learningProgress.ts`。

## 小岛、模型与界面

- 柔和海岛、木质设施与圆润图标构成主要视觉语言，区域之间保留活动空间。家园主入口收在右下角，不使用整条白底底栏或顶部区域跳转栏。
- 场景活动按五个区域整合成图形入口，土地单独显示当前播种/照顾/成长/采收状态。设施不再使用隐形大范围点击代理，场景图标避开伙伴及主要面板，减少误点。
- 种植区使用带木纹的高床、土壤颗粒、成长阶段模型和通行栅栏；游乐区加入球场标线及七色木琴，休闲区加入野餐阅读垫，营地补充布旗徽记。种植面板按横竖屏调整位置。
- 岸边岩石采用不对称圆角切面、浅色矿纹与少量鼠尾草色苔痕；休憩石保留平顶站位，篝火石圈使用扁平暖灰卵石，踏石小路改为不规则浅色石板。石材使用顶点配色，共享材质，无新增贴图下载。
- 当前手势为 **单指旋转、双指拖动平移、捏合缩放**；选中宝可梦后，在紧凑互动卡片中开启跟随。使用双指平移可避开 iPad 系统三指撤销/重做手势。
- 跟随镜头追踪伙伴位置与活动状态；在本次应用会话中，从其他页面返回家园会保留场景运行状态。不要将此理解为重启后恢复每只伙伴的精确动画帧。
- 伙伴相遇时会提前绕行；共享停靠点被占用时在旁边停下，重叠出生会稳定分开。设施路线会绕开停着的伙伴，转向沿最短角度过渡，避免互相顶回造成持续抖动。
- 在家园 **45 秒无操作**后自动观察伙伴，每个镜头约 **18 秒**，优先轮流看不同伙伴；轻触、拖动、滚轮或键盘立即停止，互动面板、学习页面、手动跟随和后台状态下暂停。家长可关闭“闲置时观察伙伴”；系统启用减少动态效果时使用固定机位切换，不做飞行和环绕。
- 388 只宝可梦均已登记 GLB 模型资源；模型索引为 `src/data/pokemonModels.json`，资源位于 `public/models/pokemon/`。当前项目并非默认依赖 Tripo 临时生成模型。
- 行为与习性由 `src/data/behaviors.ts`、设施系统和作息逻辑驱动。环境具有昼夜变化、光影和画质自适应；高画质可由家长设置。晴天、多云、微风、小雨按本地时间表变化，不获取位置；天气影响种植和伙伴行为。背景音乐按场景及时段切换，自然声音包含海浪、树叶、鸟鸣、雨声和夜间虫鸣，教学/录音时遵守声音避让。
- 当前公共图标由 imagegen 绘制并切成透明 PNG，统一经 `src/icons/index.tsx` 使用；色板已迭代为海岸蓝、暖黄和柔和纸张底色，旧 SVG 源稿保留用于回溯。

- 欢迎页与家园提供公告及未读红点；家园可隐藏全局 UI 进入沉浸模式。操作帮助复用 `FeatureGuide`，以图形步骤、短语音和目标定位说明操作，不自动代替消费或上传。

资源处理与设计记录：[GO 模型接入](docs/pogo-assets-upgrade-20261014.md)、[初代完整接入](docs/pogo-kanto-upgrade-20261014.md)、[Pokopia 资源评估](docs/pokopia-asset-evaluation-20261015.md)、[图标验收](docs/swsh-icons-acceptance-20261015.md)。这些记录描述各自当时的范围，不代表全部资源或所有设备均已完成视觉验收。

## iPad 安装、更新与离线准备（暂停发布，保留恢复说明）

当前使用 **Safari 添加到主屏幕的 PWA**，不是原生 iOS 安装包。项目已有专用本地服务：

```bash
# 先准备覆盖此地址的可信证书，再启动；不要与已有服务重复占用端口。
IPAD_HOST=192.168.1.2 node scripts/mobile/serve-ipad.mjs
```

服务读取 `certs/cert.pem`、`certs/key.pem` 和正式构建 `dist/`，并提供：

| 入口 | 用途 |
|---|---|
| `https://192.168.1.2:4173/` | 游戏与离线更新 |
| `http://192.168.1.2:4189/` | 本地安装引导及已准备好的公开证书下载 |

以上 IP 是当前测试环境地址；换网络或地址后，需要相应调整证书及服务。安装引导文件位于 `output/ipad/`。已有证书和引导不需要每次构建重新生成；证书过期时需重新配置。私钥留在 Mac，不传给 iPad。

1. Mac 与 iPad 连接同一局域网，确认 HTTPS 证书已被设备信任；不要跳过证书警告。
2. Safari 打开 HTTPS 游戏地址，通过“分享 → 添加到主屏幕”安装。
3. 从主屏幕打开，在“安装与离线准备”查看页面/模型与火山配音进度，保持联网和页面开启，等待“离线资源已就绪”。图标出现不代表离线准备完成。
4. 更新时点“重新检查”，核对当前与目标版本；失败后可重试，已完成资源可继续复用。不要靠卸载清缓存来更新，以免丢失本机进度。
5. 更新准备完成后退出并重开。真机离线验收时关闭 Wi-Fi、完全退出，再从主屏幕打开，检查家园、故事和配音。

更新服务必须能从 iPad 访问；Mac 休眠或离开局域网时不能下载更新。离线准备完成后，正常游玩不依赖 Mac 在线。浏览器可能回收缓存，重要存档请定期导出。

已有用户使用 `dist/` 时，发布应先构建到独立目录、完成校验，再整体切换并保留上一版本；不要让更新端点暴露尚未构建完整的目录。最新发布证据见 [图形优先与直接操作](docs/ux/interaction-space-next-20261017.md)及其引用的线上/iPad 清单验证。

## 火山离线配音

台词在构建期通过火山豆包语音合成生成 MP3，完成响度标准化后打包。设备播放本地录音，不包含火山密钥，也不调用收费合成；不回退到设备系统合成。

当前发布清单包含 **56,150 条录音、256 个家庭版离线配音包**（2026-10-17 清单；在线版使用独立小包）。中文旁白使用小雪，英文旁白使用慢速 Allison；角色音色配置见 `scripts/voice/cast.ts`。

新增或修改台词后：

```bash
npm run voice:collect
python3 scripts/voice/volc_tts.py build voice/lines.json
npm run voice:coverage
npm run voice:verify
npm run build  # 网页构建不需要另做家庭离线配音包
```

合成步骤会产生火山费用，已有文件会跳过。凭据默认读取 `~/.config/volcengine/config.json`，也可通过 `VOLCENGINE_CONFIG` 指定；优先使用 `services.speech_tts.credential_ref`，未配置时沿用已有 `speech_asr` 凭据引用。合成账号仍须具备对应语音资源授权和可用额度。不要把密钥写入源码、日志或安装包。

- `collect-lines.ts`：收集固定台词及动态组合。
- `check-coverage.ts`：检查运行时话术是否被收集。
- `verify-pack.py`：检查文件、火山成功回执及标准化记录，并拒绝系统 TTS 回退。
- `normalize.py`：通过 ffmpeg 统一响度。
- `pack.py`：生成离线包和文件字节索引。

出现 `403 / requested resource not granted` 时检查账号资源授权或额度，不应改用本地合成掩盖缺失。恢复后运行同一合成命令即可补齐；只有所有配音检查通过，才发布新版本。

## 存档与恢复

- 训练师、宝可梦、学习记录与跟读录音存于设备浏览器/应用的 IndexedDB，没有自动跨设备云同步。头像也在本地处理和保存。
- 不同域名、协议、端口和 APK 容器可能拥有独立存档；更换访问地址前，先在家长中心导出存档 JSON。
- JSON 存档备份不包含单独保存的跟读录音和小日记。日记页面已有单条原声下载；完整数据迁移仍需后续补齐，不能把 JSON 导出当作全量备份。
- 读取失败会显示恢复提示，不会把失败当作“没有存档”再写入空白进度。
- 同源新版本窗口使用单窗口写入锁，并通过数据库修订号防止旧快照覆盖。提示“游戏已在另一个窗口打开”时，关闭另一个游戏窗口后继续；更新后请关闭旧版窗口再重开。
- 导入前校验字段、宝可梦编号和课程进度；合法导入会保留导入前备份，家长中心可恢复。保存失败会保留待写入状态供重试，恢复前应保持页面打开。
- 备份和恢复不等于永久云备份；卸载应用、清除网站数据或浏览器存储回收仍可能导致本机数据丢失。

实现见 `src/lib/db.ts`、`src/lib/saveValidation.ts`、`src/lib/saveSession.ts` 与 `src/store.ts`。
